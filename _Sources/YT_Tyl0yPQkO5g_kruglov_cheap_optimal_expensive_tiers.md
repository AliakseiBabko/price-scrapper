## Cross-Tier Coherence — User-Added Framing, Not From the Source

The source's own closing statement explicitly argues you should **mix**
tiers per system based on personal priority (e.g. budget doors + optimal
plumbing/floors + premium ceiling) — it does not argue tiers must match
across systems. The user, reviewing this content, added an important
independent point not stated by the source: **some tier choices carry
real physical/technical dependencies on other systems**, distinct from
mere aesthetic mismatch — e.g. a hidden/concealed floor-to-ceiling
interior door has consequences for which ceiling construction is
compatible, and a concealed mixer valve needs wall depth the wall
construction must provide. This distinction (technical dependency vs.
taste mismatch) is recorded on the new page's own "Cross-tier coherence"
section and should be watched for on every future system as sources
accumulate — not something this single source states itself.
