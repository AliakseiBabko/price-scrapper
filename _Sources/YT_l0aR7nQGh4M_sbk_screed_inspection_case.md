## Flooring / Cost Drivers — Developer Screed Acceptance Testing: Real Instruments, Real Thresholds

- **⚠️ Two distinct instruments, two distinct properties being measured — don't conflate them**: (1) a **склерометр** (rebound/impact hammer, "ударный импульс" method) fired 10 times and averaged, measuring the screed's **compressive strength class**; (2) a **ротационный нивелир** (rotary laser level) used to map **surface flatness/level variation** across multiple points — a completely different defect axis from strength.
- **⚠️ Real reading in this case: screed rebound-hammer average ≈11.3 (stated as "M100" class)** — the speaker states this is **roughly one-third below the code norm ("норматив") for residential-space floors**, i.e. a real, checkable strength shortfall, not just a subjective "feels soft" impression.
- **⚠️ Separate adhesion/pull-off test performed with square 50×50mm test tabs glued to the screed surface, torn off with a calibrated instrument**: reading **0.35 MPa against a stated 1 MPa norm for a base intended for laminate, quartz-vinyl, or tile** — roughly **3× below the required pull-off strength**. **For parquet specifically the norm is stricter still (0.5 MPa)** — this same screed fails that threshold even more clearly.
- **⚠️ Level-variation (flatness) reading, a real worked number**: apartment-wide code tolerance stated as **≈5mm across the whole unit**; in this apartment, **just one corridor alone** showed a **0 to -15mm** spread across five arbitrarily-chosen points, and a separate two-corner check in the same corridor found **≈2cm (20mm)** difference between corners — **several times over the whole-apartment tolerance, found in a single room**. Correcting a variance like this before finish flooring requires an added self-leveling fill layer over that footprint — a real added-material cost not visible at handover unless measured.
- **⚠️ Consequence branches explicitly by intended finish flooring, not a single verdict for the whole apartment**: if **parquet** is planned, this screed **must be fully demolished/removed** — its strength (well under the parquet-specific 0.5 MPa threshold) will cause cracking, delamination, and swelling under a rigid wood floor. If **quartz-vinyl** is planned instead, the same screed can potentially be salvaged: grind the surface, reinforce with a strengthening compound (e.g. "ПроФас"-type) or an epoxy primer with sand broadcast, then apply a self-leveling layer up to **15-20mm** on top — a lower-cost remediation path than full demolition, but only for the more tolerant floor covering.
- **⚠️ Named structural-mismatch failure mode if the strength check is skipped**: applying an overly strong/rigid leveling material on top of an already-weak screed **doesn't fix the weak layer — it tears it apart**, because the stronger top layer doesn't flex/fail together with the weaker base beneath it. The pull-off/strength test exists specifically to select a compatible leveling material, not just to grade the screed pass/fail.
- **⚠️ Developer ("застройщик") semi-dry screed ("полусухая стяжка") is characterized as an industry-wide, structurally one-time-use product, not a factory-defect anecdote**: the specialist states this from repeated hands-on experience across multiple jobs — when later demolishing tile bonded to a semi-dry developer screed, the screed itself crumbles away in chunks along with the tile, unlike a properly mixed "wet" (classic, "мокрая") screed, which stays intact and reusable even when tile is removed a decade later. Practical implication for a buyer planning a later flooring change: a wet screed preserves future re-flooring options; a semi-dry developer screed generally doesn't.
- **Practical recommendation stated directly**: given the above, the speaker's stated preference is that developers not pour any finish screed at all, leaving each owner to select and pour a screed matched to their own chosen flooring — echoing (independently) this store's general theme of skepticism toward as-delivered developer rough-work quality.
