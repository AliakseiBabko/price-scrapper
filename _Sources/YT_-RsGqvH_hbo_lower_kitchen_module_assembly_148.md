## Furniture / Built-ins — Lower Kitchen Module: Genuinely New Content

- **Countertop-support metal-bracket installation, not previously recorded in this store**: offset 50mm from the module's side panel, mark in pencil, align the bracket's front edge to the mark and its top edge to the side panel's top edge, then fasten with the supplied screws — repeat per bracket at the same 50mm offset on every module needing countertop support.
- **Inter-module tie (межсекционная стяжка) connection technique, full sequence**: clamp adjoining modules' side panels together with bar clamps; measure the module depth and halve it to find the tie's horizontal position; mark two points on that line, one ~50mm up from the bottom plane and one ~50mm down from the top plane; center-punch both points; drill straight through both side panels with a 5.5mm bit; vacuum both the holes and the surrounding module interior thoroughly before inserting hardware; pass the tie's internally-threaded barrel through the drilled hole, thread in the screw, and tighten with a driver while holding the barrel stationary with a flat screwdriver (to stop it spinning with the screw). Repeat per adjoining module pair.
- **Bottle-rack (бутылочница) module runner placement rule, genuinely new**: unlike a standard drawer module's paired runners at matching heights, a bottle-rack module's two runners are deliberately offset — one mounted low, one mounted high on the opposite side — rather than level with each other. Explicit warning that installing them level (like a normal drawer) is a common, hard-to-notice-until-later error requiring a partial rebuild to fix.
- **Bottle-rack top-panel marking for countertop fixing**: find the panel's width centerline and mark it full-length; measure 60mm in from the front edge and mark that point on the centerline; measure 60mm in from the rear edge and mark that point on the centerline; center-punch both marks and drill 3mm pilot holes for the countertop-fixing hardware.
- **Cross-module height alignment technique, using height-adjustable legs and a laser level**: determine each module's design-spec height from the kitchen drawing, transfer that height as a floor-referenced mark, set a laser level so its horizontal plane aligns with the mark, then adjust each module's legs (clockwise to lower, counter-clockwise to raise) until its top surface matches the laser plane — start with the corner/anchor module, then align each subsequent module against both the laser plane and its already-aligned neighbor.
- **Cross-module depth alignment technique**: push all modules back against the wall as far as possible, then hold a long straightedge (or long level) against the front faces and push forward any module whose front face sits recessed relative to its neighbors, so all front faces land on one common plane.
- **Built-in-fridge-housing module sequencing, distinct from a standard module**: install legs on the base panel *before* assembling the rest of the carcass (installing legs after the carcass is tall/assembled is described as impractical); this module's own side panels join via the eccentric-hardware system same as elsewhere, but its height and weight make the final lift-into-place step an explicit two-person-only operation (matches the general two-person-lift rule already recorded in this store, restated here specifically for this heavier module type).
- **Explicit context-setting, up-front warranty framing**: inspect every module for shipping damage *before* starting assembly — the source states no damage claim against the manufacturer is possible once assembly has begun, a stronger and more explicit framing of the inspection-first rule than this store's existing content states.
