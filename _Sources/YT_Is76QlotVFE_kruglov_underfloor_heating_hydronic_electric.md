## Genuinely New Content — Electric Heating-Cable Sub-Taxonomy

Two distinct electric cable-based product types, both using the same twin-conductor cable technology but built and specified differently:

- **Thick bare heating cable (6.7mm)**: embedded directly into the screed itself, roughly 3cm below the finish surface (screed above it typically carries tile + tile adhesive). **Power density is field-adjustable by installation spacing** — the same cable laid in tighter serpentine loops yields higher watts/m² (stated range: 180-450 W/m²), and unconstrained by any fixed mat width — can be laid in any custom shape/area. Trade-off: slower heat-up, since heat must pass through the full screed + adhesive + tile stack before reaching the surface. [source: [[_Sources/YT_Is76QlotVFE_kruglov_underfloor_heating_hydronic_electric|Is76QlotVFE]]]
- **Thin heating cable pre-mounted on a mesh mat ("греющие маты")**: 2.8mm cable, sold as a ready-made mat sized to a target area, comes with its own reinforcing mesh and a corrugated conduit for the temperature sensor built in. Simpler to install for a standard rectangular area than the bare cable, but constrained by the mat's fixed width and a lower power ceiling (**stated range 130-300 W/m², brand-dependent — this cable type cannot be pushed past that range**). Can be set in either self-leveling compound or tile adhesive. **⚠️ Never install a mat-based heating cable directly under laminate with no screed/adhesive layer above it** — always needs its floated compound layer over it regardless of finish type. [source: [[_Sources/YT_Is76QlotVFE_kruglov_underfloor_heating_hydronic_electric|Is76QlotVFE]]]

## Genuinely New Content — Thermostat Taxonomy

**⚠️ Four independent classification axes for underfloor-heating thermostats, useful as a buying checklist**: [source: [[_Sources/YT_Is76QlotVFE_kruglov_underfloor_heating_hydronic_electric|Is76QlotVFE]]]

1. **Control interface**: mechanical dial, touchscreen/capacitive, or physical buttons.
2. **Programmability**: non-programmable (simple on/off + set-temperature) vs. programmable (schedule when it activates/deactivates and for how long, with separate weekday/weekend schedules on some models).
3. **Connectivity**: smartphone-app-controllable vs. not — some manufacturers sell visually-identical units where only one variant has app control, so check this specifically rather than assuming from appearance.
4. **⚠️ Sensor-dependency — a real failure-mode distinction, not just a feature checkbox**: a standard thermostat relies entirely on its own wired floor sensor (run through a corrugated conduit under the heating element) — **if that sensor later becomes physically embedded/inaccessible and fails (e.g. sealed under finished tile with no access), the entire heating system stops working** and either the thermostat must be replaced for one that doesn't need the wired sensor, or the finish flooring must be broken open to replace the sensor. Some models instead include a **built-in air-temperature sensor as a fallback** — less precise than the wired floor sensor, but keeps the heating functional if the floor sensor fails or was buried inaccessibly. **Recommendation implied: prefer a thermostat with air-sensor fallback capability, specifically as insurance against this failure mode.**
