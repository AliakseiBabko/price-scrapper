## Rules / Heuristics — Genuinely New Techniques

- **⚠️ A redundant second access point onto a loggia/balcony can be converted from a door opening into a window opening — a creative technique not previously seen in this store.** The source's explicit reasoning: a loggia only needs one door for access; a second doorway onto the same loggia serves no function ("why would a client need two exits to a fairly useless loggia? Right, for nothing"). Converting the redundant opening to a window instead freed the adjoining wall for a false wall (radiator niche) and a corner sofa placement that wouldn't otherwise fit. **General rule: when a room has two access points to the same adjoining space, check whether one is actually redundant before assuming both must stay doors** — a spare doorway can sometimes be repurposed as a window (or vice versa) to solve an unrelated layout problem elsewhere.
- **A false wall's plane should be chosen to avoid further narrowing a window opening the client already perceives as too small — even when a simpler, narrower-wall solution exists.** The source explicitly rejects the easiest option (narrowing the kitchen-to-window opening slightly to reach a pre-planned wall) specifically because the client stated the window already feels small and is "principally against" any further narrowing, however minor — instead building a stepped/notched false wall that reaches a different wall plane, at the cost of extra construction complexity. **General rule: a stated psychological/comfort requirement in the technical brief (not just a physical constraint) should override the simplest construction option when the two conflict.**

## Mistakes / Warnings

- **An acute-angle (<90°) corner in a room is functionally near-useless — no shelving, hooks, or storage can be sensibly fit into it** — a defect found in the original designer's layout, corrected in the replan by filling the corner with a small false-wall triangle to make it a workable near-90° angle. Reiterates and reinforces this vault's existing "aim for rectangular rooms" design philosophy with a specific acute-angle worked example (distinct from the more commonly-cited obtuse/skewed-corner cases in this store).
- **A dead/unused corridor's full length can become a genuine walk-in closet/wardrobe, not just incidental storage** — the replan converted what the source calls "useless, meaningless corridors" from the original designer's layout into a ~3.25m-long walk-in closet by building one straight dividing wall — reinforces this vault's existing "recover dead circulation space" planning principle with a larger worked example than previously recorded.
- **A WC/toilet room's width should be checked against both a comfortable door-opening width and correct reveals on both sides, not just a stated minimum** — the replan's own worked example: reserving 700mm for the toilet room past its dividing wall netted an actual 900mm clear width (not the initially planned 800mm) once other fixtures were placed, which was enough to support a 70cm-leaf door opening with two correct reveals — reinforces (rather than contradicts) this vault's existing door-reveal-formula content with a case where extra clearance emerged as a byproduct of correct fixture placement, not a deliberate oversizing.
