## Balcony / Loggia — New Technique Detail: Two-Layer пеноплекс Install Sequence

3. **Full materials/tool list for a professional two-layer install**:
   пеноплекс "Стена" (textured one side for plaster adhesion — the
   manufacturer's newer product line, replacing the older practice of
   hand-scoring a smooth board with a utility knife to create "hatching"
   for adhesion, still shown here as a fallback when only single-side-
   textured stock is on hand), пеноплекс "Комфорт" and "Фундамент" for the
   floor, FastFix foam adhesive, dish dowels (roofing-type and polymer-
   dish variants), facade fiberglass mesh ("panzer mesh", 85mm cell),
   Aquapanel (Knauf), Ceresit adhesive/primer, Knauf cement plaster, Weber-
   Vetonit self-leveling floor compound.
4. **Wall verticality tolerance stated explicitly**: max 2cm deviation
   from plumb across a wall before it's treated as a real problem
   requiring correction, not just cosmetic unevenness.
5. **First-layer adhesive technique**: apply foam adhesive 3cm in from
   the panel edge around the full perimeter, then zigzag-fill the center;
   wait a fixed **4 minutes** after applying before pressing the panel in
   place (no mechanical fasteners on the first layer at all — pressure-
   only, held ~30 seconds); stagger/offset seams between rows to create a
   T-joint cross-bond pattern (perekhlyost/perevyazka) rather than
   continuous vertical seams.
6. **Second layer applied perpendicular to the first layer's orientation**
   (cross-bonded) and additionally mechanically fixed — but critically,
   the second layer's dish dowels anchor into the *first insulation
   layer itself*, not into the wall/structure — the first layer is
   already secured to the actual wall/metal-frame structure, so the
   second layer only needs to be tied to the first.
7. **Exception requiring mechanical fixing even on the first layer**:
   at a metal-frame-to-glazing junction with no solid gas-block backing
   behind it, foam adhesive doesn't bond reliably — this specific
   junction must be mechanically dowelled even on the first layer (using
   a screw-with-press-washer substituted for a nailed dowel when the
   nail-gun tool wasn't available on site that day — an improvised but
   explained workaround, not the default method).
8. **Anchor density stated**: roughly 5-6 dish dowels per square meter
   (distributed top/center/bottom and at panel-to-panel joints);
   dowel holes drilled with a 5cm setback from the panel edge.
9. **Outlet-box (подрозетник) mounting — a documented bad-practice
   warning**: some installers glue the outlet box into foam adhesive
   alone, which risks the box tearing out of the wall together with a
   plug when someone yanks a cord — reliability concern, not a cosmetic
   one. **Correct technique for a balcony/exterior-type wall**: use a
   cement-based adhesive (not a gypsum-based one, which is only for
   interior work) with a keyed/undercut recess so the adhesive flows
   behind the box lip, functioning like a mechanical anchor that can't be
   pulled straight out. Final outlet-box depth must be back-calculated
   from the full finished-floor buildup (insulation + screed + tile
   adhesive + tile) before drilling.
10. **Floor panels intentionally left un-dowelled, weighted-cure method**:
    floor insulation panels are glued only (no fasteners) and held down
    during cure with simple weight — 1-2 standard 25kg dry-mix bags,
    already on site for other work — rather than a dedicated press tool.
    **Sequencing tip to avoid crushing insulation during the same job**:
    insulate the walls (both layers) first while leaving roughly a 20cm
    floor-edge strip unfinished, so a ladder/stool used for ceiling work
    isn't stood directly on finished floor insulation panels before
    they're structurally backed by the floor's own second layer/finish.
