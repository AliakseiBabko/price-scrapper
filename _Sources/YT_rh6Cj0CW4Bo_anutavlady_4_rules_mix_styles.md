## Design Concept — Style-Mixing-Within-a-Space Rules (tangential value only)

- **⚠️ The 80:20 ratio rule (extends to 60:30:10 for three styles)**: one style should dominate ~80% of the interior, with a secondary style at ~20% — explicitly generalized to a three-style mix at roughly 60:30:10, with an explicit caution not to treat these as strict formulas. **A close numeric cousin to the 70:30 rule already on this page from `Q7A1e_V0s3c`** — both sources are the same channel, so this is likely the earlier, single-space-scoped version of a principle that channel later extended to a cross-room context in the newer video (already captured on the page from that source), not independent corroboration.
- **⚠️ Architecture dictates the primary/base style; anything can be the secondary/accent style**: the base style must match the building's own architectural character (ceiling height, structural features) — e.g. a high-ceilinged old-fund building can carry classical detailing as its base style, while a standard modern panel-building apartment cannot without looking "borrowed"/absurd (worked negative example: exposed timber beams and full Provence styling forced into a standard high-rise apartment). In a standard apartment, period/ornate/rustic styles should only appear as accent-level secondary elements (a single antique cabinet or table), never as the dominant, architecture-level styling (wall/ceiling/floor treatment) — those should follow the building's own real character. A ceiling height meaningfully above standard (cited: just over 3m) is given as the deciding factor for whether classical wall/ceiling detailing (molding) can work as a base style even in new construction.
- **Rule 3 (Anuta Vlady's own numbering) — match unrelated furniture/decor pieces via a "friends, not close relatives" heuristic, by one of three shared traits**: color, size, or form/shape. Named worked examples: a classic black door "befriended" by a contemporary metal-framed element via shared color; a classical mirror and chandelier "befriended" by a modern coffee table via shared bronze/gold tone; a modern plastic table fitting into a vintage-furniture room via a shared classical *form*, despite differing materials/eras.
- **Rule 4 — distribute secondary-style elements evenly throughout the space rather than concentrating them in one zone**, to achieve a balanced eclectic result rather than a lopsided one — the worked example shows a room where classical elements dominated one side being deliberately rebalanced by adding a minimalist metal shelf above a classical table specifically to prevent visual "weight" pooling in one area.
