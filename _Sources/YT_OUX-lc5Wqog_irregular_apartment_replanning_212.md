## Planning Rules — Irregular-Layout Full Replan, Worked Techniques

- **Developer-installed non-structural partition quality, framed as a running joke/complaint but with a real technical consequence**: the source states these are near-universally poorly built (walls thin/wavy enough that voices carry clearly through them, as demonstrated on camera) and recommends demolishing them to the ground and rebuilding regardless of apparent position accuracy — treat any developer non-structural partition as a placeholder marking "a wall belongs roughly here," not a usable base.
- **Narrow-wall-segment usability threshold, worked example**: a 230mm-deep wall segment (between a doorway edge and an adjacent wall) is stated as insufficient even for a wardrobe's own back panel, let alone the wardrobe itself — below this threshold, the segment should be treated as unusable for built-in storage and reallocated (in this case, by shifting the offending wall toward an oversized adjacent kitchen zone) rather than accepted as a compromise.
- **Kitchen-alcove-depth-matching rule**: a masonry alcove/box built to house kitchen cabinetry should be built to the kitchen's own standard module depth (600mm in the worked example), not an arbitrary larger depth — an oversized alcove wastes floor area the cabinetry itself won't use; the fix, reducing the box to exactly 600mm depth, both reclaimed space and gave a cleaner installation.
- **Doorway rough-opening width threshold, explicit and numeric**: a 1100mm-wide developer-built opening is stated as unusable for installing any standard interior door leaf, and additionally lacks the reveal/return framing (отбортовка) a correct door installation requires — both defects independently necessitate demolishing and rebuilding the opening, not just widening it.
- **WC minimum-width shrinkage from plastering, a real-numbers worked example**: a developer-built WC measuring 900mm wide is stated to functionally shrink to ~800mm once walls are plastered and trued — at 800mm, only a toilet fits; not even the smallest sink. This is presented as the reason a full WC/bathroom replan (not a cosmetic fix) was necessary, since the client's fixture list (toilet, washing machine, sink, shower, and a full bathtub) could not physically fit any arrangement within the existing footprint regardless of layout cleverness.
- **Radiator false-wall thickness varies by underlying wall type, three cases shown in one project**: a light (~50mm) false wall suffices to recess a radiator against an ordinary partition; the same technique against a load-bearing wall (which cannot itself be chased/recessed into) needs a full 150mm-deep false wall instead, since the entire radiator depth must be absorbed by the false wall rather than partly recessed into the substrate. `confirmed`, a specific numeric contrast (50mm vs. 150mm) not previously recorded this precisely in this store — extends the store's existing floor-standing-radiator mitigation content (see this vault's new [[12_Engineering_and_Systems/Heating|Heating]] page) with the wall-mounted equivalent.
- **Duct/utility-box minimal-sizing technique, re-corroborated**: build the box around plumbing/utility risers to the smallest dimensions that still clear the pipework, rather than an oversized box — matches this store's existing minimal-duct-box content from independent sources.
- **Door-opening reveal (отбортовка) purpose, stated explicitly**: the reveal framing exists specifically so a door frame can be correctly squared/adjusted at install time — an opening built without it (as with the rejected 1100mm opening above) cannot be corrected after the fact without rebuilding.
- **New interior door install result, worked example**: a properly-built opening let a door install with correct reveal clearance and a 95° swing that doesn't obstruct a person entering — cited as the practical payoff of building the opening correctly the first time rather than working around a developer-built one.
- **Final fixture layout achieved in the WC/bathroom after replanning**: toilet (900mm clear-use width), a reduced-depth washing machine, a utility cabinet, a sink positioned opposite the entry (mirror-on-entry placement, so the client sees themselves immediately on entering), a full bathtub, and a shower (~800×1100mm) — all fit within a footprint the client's own attempt at self-planning could not accommodate any single one of comfortably, per the video's own before/after framing.
