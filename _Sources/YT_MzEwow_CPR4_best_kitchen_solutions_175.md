## Kitchen

- **A kitchen island is only appropriate in kitchens ≥14 m²** — smaller kitchens don't have adequate passage clearance for one.
- **Island clearance rule**: minimum **80cm** clearance required on every side of the island except the one side that may face a sofa/dining area — if any other side has less than 80cm to the nearest cabinet/window wall, don't install an island at all (80cm allows two people to pass comfortably).
- **Island minimum width: 1 meter** — if available depth for an island is ≤60cm, skip it entirely.
- **Never split a 1m-wide island into two back-to-back storage zones accessed from opposite sides** — this eliminates any usable knee space, leaving the island functional only as pure storage, not as a seating/eating surface. For a comfortable seated island, leave a **minimum 35cm (ideally 40cm) knee recess**. `confirmed`, explicit numeric figures.
- **Island height should match its actual intended use, not a universal standard**: cooking-zone height should match the main counter's chosen height (determined via kitchen-company showroom visits/trials before finalizing); bar/eating-surface height should be chosen by trying several stool heights and picking what's comfortable for the household — no single correct bar height exists either.
- **Avoid countertop-embedded pop-up/retractable outlets** — food/liquid residue (honey, jam, etc.) reportedly jams the extend mechanism over time; prefer a flush, separately-lidded (static, non-extending) outlet housing instead. An island specifically still needs its own outlets (no better place to route them), but avoid the pop-up mechanism type.
- **Dishwasher-to-sink handedness ergonomic rule (extends this store's existing handedness-based placement content)**: if the household member who washes dishes is right-handed, place the dishwasher to the **left** of the sink. Reasoning: dishes go table → sink (scrape/rinse) → dishwasher; the working hand holds the plate near the sink, so the free hand needs the dishwasher on the same side to place it in without an awkward reach/twist. **A designer/planner should always explicitly ask which hand the household washes dishes with**, rather than defaulting to one side. `confirmed`, explicit mechanism given.
- **Upper kitchen cabinet modules are frequently never actually used functionally in practice, per this practitioner's stated real-world observation** — recommends making them decorative-only (blank door fronts, no functional hinges/opening hardware, no interior fitting cost) as a legitimate cost-saving measure with no visual downside. `single-account`, practitioner's stated experience across many projects.
- **Cooking-zone task-lighting control-point rule (extends this store's existing lighting content)**: the light over the "main cooking zone" (the counter section between sink and cooktop) must be switched from that exact zone itself — not a remote switch location, not an unpredictable sensor — so the cook never has to leave the zone to control it.
- **Refrigerator configuration recommendation**: prefer a fridge model without a built-in freezer compartment (fresh-zone-only) paired with a separate, larger standalone freezer unit — described as a long-tested favorite, giving substantially more usable freezer capacity than a combined fridge/freezer's small freezer section.
- **Corner-kitchen-without-a-corner-module technique**: when the layout's true corner is unusable for a full corner cabinet module (e.g. a utility riser or an adjacent bathroom wall intrudes into it) and the default response is a cramped single straight run, build a dedicated technical column sized exactly **60×60cm** at that corner instead — lets the two straight cabinet runs on either side dock cleanly against the column (their countertops don't need to form one continuous surface; a countertop segment from one run can also land on the column). `confirmed`, genuinely reusable spatial technique for a structurally/plumbing-constrained corner.
