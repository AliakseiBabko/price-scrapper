## ⚠️⚠️ 1. THE CANTILEVERED DESK (безопорный стол) — the mechanism, and its honest limits

**A fold-down desk with NO legs and no support to the floor at all** — *«стол без опорный, который не имеет никаких опор, он открывается одним лёгким движением»*. **Everything is carried by the wall fixing.**

| Property | What he states |
| :--- | :--- |
| **Work surface** | *«Небольшая, но в целом её достаточно, чтобы посидеть поработать»* — **⚠️ the shown model is 50 cm deep**, and can be made deeper to order |
| **⚠️⚠️ Height** | **NOT adjustable** — *«вылет столешницы здесь уже не регулируется»* |
| **Storage inside** | Shelves within the body; **the laptop can live in the table itself** — *«сели, достали, по-быстрому поработали»*, then it all shuts away |
| **Above it** | Optional fold-down or hinged lockers, or open shelves, specified per project |
| **Below it** | A small niche as shown, replaceable with drawers |

> **→ ⚠️⚠️ THE CATEGORY-DEFINING TRADE-OFF, and it is worth stating plainly because the vault's existing desk material assumes a conventional desk**: a cantilevered fold-down desk buys back the entire floor footprint when shut, and pays for it in **fixed height, shallow depth, and a wall that must carry the whole load in bending.** **His own framing is the home office — *«особенно в нынешнее время, когда требуется дома разместить небольшой домашний офис»*.**
>
> **⚠️⚠️ FIXED HEIGHT IS THE ONE TO WATCH. A 50 cm-deep, non-adjustable surface is a real ergonomic constraint**, and this vault already holds task-seating and desk ergonomics material that assumes the desk can be matched to the chair. **On a cantilevered desk it cannot: the CHAIR must be matched to the table, and the table height has to be settled at order stage.** **→ It also means the fixing wall must be specified for a cantilever, which is a rough-stage decision in the same family as the wall-bed anchor question.**

## ⚠️⚠️ 2. The hidden extending table — a dining table stored inside a 300 mm cabinet

**In a delivered kitchen, a cabinet that looks ordinary:**

> ***«Это настоящий рекордсмен по количеству НАПРАВЛЯЮЩИХ, которые были в нём использованы. С тыльной стороны он скрывает ЧАСТИ СТОЛЕШНИЦЫ, которые аккуратно вынимаются и устанавливаются сверху.»*** **Extended, it runs the full width of the kitchen.** **Built to order by a named designer at the firm.**

**The owner's stated use case: *«эта обеденная зона идеально подходит для шумных застолий, таких как дни рождения или Новый год»*.**

> **→ ⚠️⚠️ THIS IS A THIRD ENTRY IN A TAXONOMY [[14_Furniture/analysis/Table_Types_and_Dimensions|the tables page]] ALREADY HOLDS.** That page records extending tables and the planning error that wastes one — **a table sized for the rare maximum rather than the daily minimum.** **This is the opposite construction: the daily state is a 300 mm cabinet and the leaves are STORED SEPARATELY rather than folded inside the table.**
>
> ⚠️ **And it inherits the same planning question, so the page's existing warning applies unchanged and should be cross-referenced rather than restated**: the leaves have to be carried out, assembled and put back, which is a two-person job a few times a year. **The cabinet version removes the daily footprint cost; it does NOT remove the setup cost.**
>
> **⚠️⚠️ DIRECTLY RELEVANT TO THIS PROJECT'S PHASE 2**, where [[00_Master/Bedroom_Design_Principles|the household plan]] records that the everyday dining table lives in the kitchen zone and *«an extended table is set up here only for special events»*. **That is exactly this device's use case, and it is currently an unspecified item in this project's own plan.**
