## Genuinely New Content

- **"Think of clothing storage as a system, not an afterthought" — an
  explicit planning-order caution**: the source contrasts *drawing storage
  by leftover space* (his stated anti-pattern: "не рисовать по остаточному
  принципу") against planning a genuine storage *system* alongside (not
  after) the other rooms. This is a general planning-sequencing principle
  independent of the specific three-tier house hierarchy it's introduced
  through — worth applying to an apartment's own clothing-storage planning
  even without the multi-room hierarchy. Not previously captured as its
  own explicit framing on this vault's Furniture pages (which have plenty
  of specific sizing rules but not this named sequencing caution).
- **Entry-zone storage flooring must match the vestibule/entry-hall
  flooring (tile/porcelain), not the interior laminate used elsewhere in
  the wardrobe** — reasoning given: an entry-adjacent wardrobe area sees
  the same dirty, heavy foot traffic as the entry itself (people using it
  while still partly dressed in outdoor shoes), so laminate installed
  there wears out unusually fast. A concrete, checkable material-selection
  rule that generalizes directly to an apartment entry-hall storage/coat
  closet, independent of house scale. [source: this transcript]
- **A walk-in closet doubling as an acoustic buffer between a corridor and
  the bedrooms it serves**: placing built-in wardrobe storage at the dead
  end of a corridor that several bedroom doors open onto both solves
  storage *and* meaningfully reduces the corridor noise reaching the
  adjacent bedrooms, since more of each bedroom's shared wall now borders
  a low-traffic storage room rather than the noisier corridor directly.
  A reusable zoning principle for an apartment layout with bedrooms opening
  onto a shared hallway, not tied to the specific house floor plan.
- **⚠️ Avoid a "ping-pong" circulation pattern between an ensuite bathroom
  and a bedroom-adjacent walk-in closet placed on opposite sides of the
  bed** — if one occupant needs to get ready earlier than a sleeping
  partner, a layout requiring repeated trips bathroom→closet→bathroom
  (each with its own door open/close noise) crosses directly past the bed
  multiple times and reliably wakes the sleeping partner. **Fix: route
  both the bathroom and the closet off a single small shared entry
  nook/mini-vestibule** (lined with built-in storage) positioned so the
  bedroom's own door doesn't open directly into the bed-facing circulation
  path — described as the source's own recommended default rather than a
  house-specific one-off. This is a genuinely new *named failure mode and
  its fix*, not previously captured on this vault's Furniture pages (which
  have separate sizing/mistake content but not this specific circulation
  pattern).
- **Wardrobe depth default raised to 65cm (not less than 62cm)**,
  explicitly described as this practice's *recent* standard change,
  reasoning: budgets in both possible door-hardware/model variation and
  combined rough+finish-layer thickness. **Adds a specific
  door-vs-wardrobe collision clearance**: where a door swings close beside
  a built-in wardrobe run, only ~70mm of clearance may remain to the
  narrowest door casing — if the wardrobe ends up even a few centimeters
  deeper than planned, the door and wardrobe collide; pair with a door
  stop/bumper for protection. This is a close but **not identical** number
  to this vault's existing Wardrobe_Vocabulary_and_Sizing figures (65-70cm
  everyday clothing depth, 75-80cm outerwear, from Zemstandart) — same
  ballpark, independent source, worth recording as a second data point
  rather than assumed identical reasoning. [source: this transcript]
- **A pass-through wardrobe connecting two children's bedrooms** (entered
  from each room, closet in the middle) as a "Jack-and-Jill"-style shared
  arrangement — explicitly flagged by the source as **not suitable for
  every child age range and only a temporary layout solution (roughly a
  10-year horizon)** before the floor plan will likely need reconfiguring
  as the children grow. A concrete, honestly-caveated technique distinct
  from this vault's existing Jack-and-Jill *bathroom* content (a shared
  closet version of the same idea), worth recording with its explicit
  temporariness caveat attached.
