2. **Electrical and plumbing rough-in stage order is explicitly stated as
   flexible**: either can be done first, or the two can be run
   simultaneously — the only stated requirement is that the two crews
   communicate and don't conflict, not a fixed sequencing rule.
3. **Proactive wall-geometry pre-check at the wall-building stage
   itself, distinct from this channel's previously-captured *reactive*
   discovery of the same defect after plastering (Round 5,
   `mb-2ll0UtTo`)**: before building new partition walls, check the
   existing developer geometry and deliberately adjust the first course
   of new wall material to compensate for known deviation — reduces how
   much plaster thickness (and therefore cost and dry time) will be
   needed later, versus building walls with no reference to existing
   geometry and letting plastering absorb the full correction.
4. **Sound-insulation underlayment ("шумонет") material description and
   mechanism**: a rubberized-top, felt-backed material laid under
   flooring specifically to reduce impact/structure-borne noise
   transmission to the unit below (dropped objects, footsteps — distinct
   from airborne noise) — available in "гидро" (waterproof) and "комби"
   (combined) variants.
