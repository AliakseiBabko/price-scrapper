## Genuinely New Content

**Concealed/hidden toilet-brush-and-toilet-paper holder — new topic, not
previously on this store's toilet-accessory content**: a push-to-reveal
or pull-out concealed holder for the toilet brush and paper (marketed as
minimalist, "no visual clutter") is a real usability problem distinct
from the existing reach-distance ergonomic rule already on this page —
even a resident who learns the mechanism still has to press/pull/reach
into a recess for daily use, and **a guest unfamiliar with the specific
mechanism generally can't figure it out at all**, creating a real
guest-discomfort problem the design intent doesn't account for. Recorded
as a caution against concealment mechanisms specifically, not against
toilet-brush/paper storage in general.

**GX53 downlight fixture — new named product-type caution, extending
this store's existing general CRI-matters guidance with a concrete
example**: this puck-style recessed downlight format (popular roughly
7-10 years ago per the source, still widely used) is called out by name
for **low CRI (color rendering index)** — even bright output looks dull/
washed-out — and **poor-quality integrated optics**, producing flat,
uninteresting light despite the format's low cost (its one stated
advantage). Recommends mixed fixture types matched to scenario/task
instead, plus checking CRI and color temperature specifically before
buying any fixture (restates, doesn't newly establish, this page's
general buying-criteria guidance).

**Heated bathroom wall vs. electric towel warmer — new quantified
tradeoff, extending this page's existing wall-mounted heated-cable
concept (already documented from this same channel's `gKBzDEllg4M`) with
concrete cost/time figures not previously recorded**: a heated wall
(electric floor-heating cable run vertically under tile) costs
**roughly 3-4× more to install** than an electric towel warmer, and
**roughly 3-4× more to run**, because a towel warmer can be run on a
timer for a few hours in the evening while a heated wall needs
**2-3 hours just to reach target temperature** (heat must first warm the
tile adhesive, then the wall substrate, then the porcelain tile itself)
— so achieving "warm robe on waking" either means leaving it on
continuously (24/7) or timing a start around 3 hours before waking,
both meaningfully raising running cost versus a fast-heating towel
warmer. Framed as a real cost-vs-aesthetic tradeoff, not an argument
against the heated-wall concept itself.

**Master-switch exclusion list — new named items extending this page's
existing priority-group taxonomy**: this video's version of the standard
"always-excluded from a single-button master cutoff" list names the
**refrigerator, security/surveillance system, leak-protection system,
and the Wi-Fi router** specifically — the existing page's own priority-
group list (from Petrishin-Stroi) already covers refrigerator/heated-
floors/leak-protection/weak-current panel; router and a named security-
camera system are a fourth independent source's explicit restatement/
extension of the same exclusion concept (weak-current panel would
implicitly cover the router, but this source names it directly). Also
restates (does not newly establish) the general master-switch
inconvenience case and the "vacation-mode" scoped-switch alternative
already covered on this page from two other sources.

**Drywall-ceiling cost ratio — a new comparative figure worth logging
against the existing same-channel cost divergence, not a resolution of
it**: this video states drywall costs **"3-5×"** more than stretch
ceiling, without a separate RUB/m² figure. This is a plausible order-of-
