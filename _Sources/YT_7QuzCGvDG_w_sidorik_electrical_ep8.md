## Cable Circuits & Panel Design — Ceiling Lighting Wiring and Floor Routing

- **Ceiling lighting-circuit cable-type rule**: use 2-conductor (2×1.5) cable specifically for fixtures with no ground terminal (most recessed/spot lights lack one); reserve 3-conductor (3×1.5) cable for fixtures that need grounding.
- **Wiring diagrams for common switch configurations**: a single-pole switch breaks the phase line to a chain of daisy-linked ceiling fixtures; a two-pole (двухклавишный) switch for a central fixture splits the phase into two independently-switched lines (the same logic extends to a three-pole switch splitting into three lines); two-pole pass-through/3-way switches are used specifically where hallway/living-room lighting needs control from multiple points.
- **A real worked room-by-room lighting-circuit plan**: bedroom/balcony — chain of surface-mounted fixtures on a single-pole switch; kitchen-living/WC — same pattern plus two-pole pass-through switches for hallway/living-room shared control; kids' room — 3 surface-mounted spot fixtures on one single-pole switch group, plus a central 2-circuit fixture on its own two-pole switch.
- **Floor cable routing under screed uses ПНД (high-density polyethylene) corrugated conduit, never ПВХ, specifically because ПНД doesn't deform underfoot and is meaningfully stronger** — conduit color (orange/black seen in this project) is purely cosmetic and doesn't affect function. **Independently corroborates and adds mechanism to this store's existing conduit-material rule** (grey PVC for exposed/ceiling routing only; colored ПНД for floor/embedded routing, previously explained via a combustion-safety distinction) — this source's stated reason is mechanical durability under foot traffic, a genuinely different but compatible rationale for the same material choice.
- **Fast conduit-clip fastening technique**: a powder-actuated (gas-cartridge) fastening tool is the fastest way to secure conduit clips to a bare floor — doesn't need to be purchased outright, can be rented (real rental-location reference: Minsk, see Region note); a qualitative cost claim (no absolute figure given): the cost per "shot" is cheaper than a single dowel-nail, with drastically higher installation speed than manual drilling.
- **Where powder-actuated fastening would puncture an underlying soundproofing membrane, switch to adhesive-mounted clips instead** — the speaker tested foam adhesive and sealant before settling on **hot-glue-gun adhesive** as the most effective: very strong bond, sets fast enough to resist being kicked loose by foot even before full cure, and needs no drilling at all. Flagged as a surprisingly versatile adhesive discovered specifically through this on-the-job experiment.
- **Long conduit-and-cable pull technique for a large job**: pull ~100m of conduit and ~100m of cable together outdoors in one pass, using the conduit's own built-in steel fish-tape wire (tie the cable to it and pull through) — this project instead used the building's own long shared inter-apartment corridor for its long pulls, since it was available and long enough, rather than going outside.
- **Network cable spec used**: copper, category FTP 5e, shielded — the shield's function is EMI/interference protection.
- **New incoming service cable planned to fully replace the developer's original one**, rerouted at the panel-niche cable-entry point specifically to avoid cutting further into the wall and to make room for the network cable and the extended fiber-optic run into the same niche.
- **Panel-mounting technique**: set into the plaster-finished niche on gypsum plaster, secured/positioned with foam adhesive, leveled and set flush with the wall face; cable-entry holes pre-cut into the panel enclosures before mounting.

## Planning Rules / Cost Drivers — Reusable Temporary Wiring

- **Use reusable quick-disconnect terminal blocks (EKF-brand) for all temporary construction-phase lighting and outlets** — to remove a temporary outlet before plastering, unclip the terminal block and insulate the wire ends rather than disassembling the outlet itself; makes the entire temporary-lighting/outlet kit reusable project to project. **Real reuse practice**: light bulbs and lamp sockets (patrons) from this practitioner's earlier khrushchevka project are reused here rather than bought new, explicitly framed as avoiding the real ongoing cost of buying new LED bulbs for every project — buy once, carry the same bulbs forward. Personal preference noted: cool-white color temperature for work lighting.

## Regulations / Permits / Approvals — Floor-Routed Cable Safety FAQ (myth-busting)

A genuine, mechanism-based FAQ segment directly addressing recurring skeptical viewer comments about floor-embedded cable-in-conduit under screed:

- **Floor-routed cable-in-conduit under screed is compliant with electrical installation rules (ПУЭ)**, not a code violation as some commenters assume, and is the *preferred* routing wherever screed thickness allows it over the ceiling.
- **Three concrete advantages of floor routing over ceiling routing, stated directly** (partially extending this store's existing floor-vs-ceiling routing cost-tradeoff rule with additional, non-cost reasons): (1) **no concealed junction boxes** — all connections happen inside back-boxes, accessible simply by removing a socket/switch plate, unlike a junction box sealed behind drywall or a stretch ceiling, both painful to reopen for a repair; (2) **shorter cable runs** — floor-routed cable "tails" are typically shorter than an equivalent ceiling-drop run; (3) **frees the ceiling entirely** — no need to box in or drop the ceiling to hide cable runs, so it can stay as-is or simply be plastered.
- **"How do you retrieve an embedded cable if something goes wrong?" — directly addressed**: you generally don't retrieve it. A failed cable is left in place (wall/ceiling/screed) and a new one is run instead; if there's a specific known failure point, only that one spot needs opening and re-terminating. The same logic already applies to cable embedded in a plastered wall or behind a drywall ceiling — both also require demolition to access, so floor-embedded cable isn't a special case.
- **"Can an embedded cable itself catch fire or melt?" — directly addressed with a stated protection-layering mechanism**: a properly installed circuit sits behind **four layers of overcurrent protection in series** — an RCBO plus the apartment's own main incomer breaker, a separate main breaker in the building's corridor/riser, and a main disconnect-with-fuses at the building's service entrance — making an actual cable meltdown "practically impossible" absent an implausible compound fault. **The one genuinely vulnerable point is a connection/junction, not the cable run itself** — which is exactly why floor-routed cable's back-box-accessible junctions (vs. a sealed junction box) are a real safety/maintainability advantage, not just a convenience one.
