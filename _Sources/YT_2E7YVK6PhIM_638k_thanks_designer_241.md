## Rules / Heuristics — Standout New Techniques

- **⚠️ A glass sliding partition can satisfy a gas-kitchen code requirement (a door must separate a gas kitchen from an adjoining room) while remaining functionally almost fully open — a genuinely valuable regulatory-compliance technique.** Russian building code requires a gas kitchen to have a separating door from any room it opens onto; a fully open-plan kitchen-living room with gas appliances is technically non-compliant. The source's workaround: install a glass sliding partition, which technically satisfies "a door exists" for an inspector's sign-off, while in its open position providing an essentially unobstructed, highly transparent opening that functions like a true open-plan layout in daily use. **General rule: when a client wants an open kitchen-living layout but has gas appliances, a glass sliding partition is a legitimate way to satisfy code without sacrificing the open-plan feel** — distinct from this vault's existing general caution against sliding/swinging glass partitions (falling glass risk), which the source explicitly flags as the tradeoff being deliberately accepted here as "the only correct answer" for this specific constraint.
- **⚠️ A currently-open floor plan can be pre-engineered for a future partition wall — pre-installed anchor-point hardware lets a later life-stage change (e.g. children arriving) wall off a room cheaply, without demolishing or redoing surrounding finishes.** The source's worked technique: build a structural box/frame at the intended future wall location now (while finishing the current open layout around it), with mounting points already in place for a sliding-partition track; years later, when the room needs to become fully enclosed, the household removes the sliding-panel hardware, attaches drywall-frame profiles to the same pre-installed anchor points, insulates, and finishes with matching wallpaper — converting an open living space into a private room "for pennies" without touching the rest of the renovation. **General rule: when a client's near-term needs favor an open layout but a foreseeable future need (family growth) will require a wall, engineer the eventual wall's anchor points into the current build now** — a genuinely reusable long-horizon planning technique, not previously recorded in this store.
- **When comparing two competing uses for the same scarce square footage, quantify both alternatives concretely before allocating the space — don't default to whichever use was planned first.** The source's worked example: a laundry-room storage extension would have added "3-4 extra coat hooks," while using that same footprint for a second refrigerator instead gave the client a second full fridge — explicitly framed as an easy call once quantified side by side, but one a less careful planner might default away from.
