## Materials / Walls-Ceilings — First-Course Leveling Masterclass

- **Why the first course matters disproportionately**: foam-glue bonds blocks quickly but does not correct leveling errors — all leveling work for a foam-glue-bonded wall must happen at the first course (laid on mortar), so everything above it can be laid fast with no further leveling needed.
- **Don't force a shared reference plane across walls that aren't structurally connected to each other** — it doesn't matter if one unconnected wall segment's base sits a few cm higher than another; that only affects raw coursing-joint positions, nothing functional. A common wasted-effort mistake.
- **Survey before deciding whether beacon-based leveling is even needed**: measure the laser-plane-to-floor distance at multiple points around the wall's footprint first. If the spread is small (real example: ~5mm across a run), skip beacons entirely — just spread a uniform ~1-1.5cm mortar layer and set blocks, correcting with a rubber mallet + level + straightedge. A larger spread (real example: ~3cm on an L-shaped run) needs full beacon leveling.
- **Beacon (маяк) product-quality distinction**: cheap foil-type beacons (~65 RUB) flex in any direction and should never be used. Use a rigid, single-axis-flex beacon type — the video names Knauf specifically, self-flagged by the speaker as reading like an ad but stated as a genuine practice preference for accuracy.
- **Mortar rest-then-remix discipline**: after initial mixing, let mortar rest/slake 5-15 minutes per the product's own packaging instructions, then re-mix before use. **Client-facing warning**: if a crew mixes mortar and immediately trowels it on without this step, stop them.
- **Beacon-setting method using tape as a reference line**: mark the intended wall footprint on the floor with tape first; set beacons so their top ridge runs exactly along the tape's edge (avoids repeated wall-line re-marking). Use small mortar dabs to set beacons on (not a full smeared bed, which makes precise leveling harder) — excess mortar can always be scraped off later, but too little means pulling the beacon up entirely and remortaring, which is worse.
- **Beacon spacing = wall thickness**: for a 100mm-thick wall, beacon ridges are set exactly 100mm apart, parallel to each other.
- **Beacon leveling sequence**: find the wall run's single highest point via laser survey; press the first beacon down there until only a thin mortar layer remains (this becomes the reference/"zero" point) and record its measured height; move to each subsequent beacon location and match the same laser-to-beacon-top distance, using a rigid straightedge/square (not a tape measure, which introduces error) to read/transfer the distance consistently. Leveling two parallel beacons simultaneously with a square laid across them is much faster than leveling each individually against a template.
- **Cross-run continuity**: once one run's beacon plane is fully leveled, the laser level can be repositioned for a different wall run without losing accuracy — just re-measure the new position against the already-leveled first plane and match that reading; no need to keep the laser fixed in its original spot.
- **Course-laying alignment**: apply mortar without fully burying the tape reference line (keep it visible); set each block precisely against the tape's inner edge — flagged as critical for the whole wall's dimensional accuracy. Sight along the block's face at an angle when the tape edge isn't visible from directly above.
- **Sequencing rule: always start block-laying from an existing fixed wall (a corner anchored to it), never from a free-standing corner outward.** Starting from a free corner and working toward a wall risks an awkward small sliver cut if the day's coursing comes up short. Starting from the wall toward the corner means any shortfall/excess at the far (unconstrained) end can be built out with plaster (if short) or trimmed with a reciprocating saw once cured (if long). Flagged as one of the single most common beginner mistakes.
- **Never pre-cut the first course around planned door/window openings** — lay the first course as a continuous run ignoring openings entirely, then cut the openings afterward with a reciprocating saw once the row is set. Faster, more accurate, avoids fiddly on-the-fly measurement errors; leftover cut pieces get reused elsewhere.
- **Verify true right angles at every corner at the first-course stage** with a mason's square (wet-room corners specifically flagged as needing precise verification) before allowing the crew to build upward from that base.
- **Mortar-bed function**: the varying mortar thickness under each block (visible once excess is scraped away) is exactly what absorbs the raw floor's unevenness while keeping every block's top in one true horizontal plane; a cement-sand bed of this kind doesn't shrink/settle afterward once cured.
- **Filler-piece technique for an odd/tight junction**: rather than forcing a perfectly-fitted odd-sized cut piece, insert a smaller filler/pillow-shaped block piece and lightly trim the adjoining block — a functional, hidden solution once finished, not worth extra effort chasing a geometrically perfect cut with no visible benefit.
- **Final first-course QC, before laying any further courses**: recheck flatness with a straightedge (tolerance here noticeably tighter than the finished-wall 5-7mm allowance from this batch's companion video — described as "a couple mm or less" for this raw base platform specifically), recheck level, recheck squareness at every corner. Only once all pass is the platform ready for subsequent courses to be laid quickly on foam-glue with no further individual leveling — the video demonstrates an entire L-shaped run built this way in roughly 20 minutes of real time once the base platform was correctly prepped.
