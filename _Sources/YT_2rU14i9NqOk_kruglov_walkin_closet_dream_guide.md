## Genuinely New Content

**Aisle width as a distinct sizing figure**: internal walking clearance inside a walk-in should never fall below **80cm** (uncomfortable, can't turn around); **90-100cm is comfortable**; **110cm+ is ideal**. New axis for this store — the existing total-width-by-configuration figures already bake in a workable aisle, but this rule lets a plan be checked directly against the aisle alone.

**Passage-through walk-ins (between bedroom and ensuite bathroom) need deliberate ventilation planning, non-negotiable** — a walk-in serving as the sole route to a bathroom carries both moisture/humidity exposure and constant traffic, so it should get the same-or-better ventilation tier as a dead-end closet, never less.

**A walk-in's entry must always have a real door — never an open portal or curtain** — fails both dust-control (bidirectional: bedroom dust into stored clothes, and clothing-shed dust into the bedroom) and reads as "colhoz"/cheap. Hinged door is Kruglov's own stated preference; sliding (pocket or surface-mounted) is an acceptable second choice.

**Three-tier ventilation system for walk-ins, genuinely new to this store**: (1) passive grilles + 1.5-2cm door-bottom gap — weak, no real driven circulation; (2) grilles (preferably low) + a forced supply/exhaust duct fan — the explicit minimum acceptable tier for any bathroom-passage walk-in; (3) full apartment-wide supply-and-exhaust ducted system extended to the closet — no-compromise tier.

**Hanging-rod/open-shelf/drawer depths named together with a garment-fit caveat**: rod section ideal **60cm**, compromise **55cm** only after physically test-fitting the household's actual hanging clothes (a shallower zone can let the door facade catch and crease garments on close); open shelves **35-45cm** (corroborates existing ~35-40/40cm shelf-depth-for-retrieval rules from Kodolov and LA BURO); comodo-style pull-out drawers **55-60cm**.

**Shelf-height ladder by content type**: thin folded items (t-shirts) 18-25cm; bulkier folded items (jeans, sweaters) 25-30cm; bedding/towels 30-40cm — new granularity within this store's existing 3-tier vertical layout (which names band positions, not folded-shelf heights within the bulky-items band).

**Lighting — two new points**: (1) motion-sensor lighting caution from direct stated experience (sensors fail to re-trigger mid-use, "genuinely irritating") — recommends a plain mechanical switch instead, a different failure mode from this store's existing spotlight-shadow caution (Kodolov); (2) a vertical-fixture cost-control technique — one or two vertical light fixtures mounted proud of shelf fronts illuminate a whole shelving block, avoiding per-shelf embedded lighting whose connection/installation labor can approach the furniture's own cost.

**Mirror placement options, extending the existing 1.7m-minimum-width rule**: besides freestanding, a mirror can be mounted on a module's own facade/door front, or on the entry door's *interior* face (visible only with the door closed, user inside).

**Shoe-storage policy**: default to visible, open (unboxed) storage — boxed seasonal rotation is "incredibly inconvenient" and causes some pairs to go unused a full season; exceptions are resale-intended pairs and genuinely rare/collectible pairs, which warrant a display-oriented solution instead.

**Open-vs-closed storage — explicit mixed-system recommendation**: fully open shelving creates visual noise (color/texture variety alone, even when tidy); fully closed slows retrieval. Recommends a deliberately mixed system (open + closed + drawers + baskets), planned zone-by-zone by content category in advance.

**Island units for large walk-ins**: a central freestanding island (accessories: watches, wallets, belts) is only proposed for walk-ins ≥10m² — below that, no room without blocking circulation.
