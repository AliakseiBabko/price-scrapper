## Walls / Ceilings — Reveal-Plastering Guide-Profile Technique

1. **German-made plastic guide profile used specifically at door/window
   reveals ("откосы") to prevent cracking as the building settles/"plays"**
   ("если блок играет, то трещину это избежать") — the speaker notes this
   profile is normally used for exterior facade work, repurposed here for
   interior reveal-plastering. Framed as the reason reveal plaster on this
   job doesn't crack the way reveal plaster normally does ("если всегда,
   когда делается здесь малярка, всегда трескается" — implying reveal
   cracking is otherwise a near-universal problem). New named technique,
   distinct from this page's existing reveal/corner-mesh content.

## Walls / Ceilings — First-Course Mortar-Bed Mechanism (extends existing corroborated content)

2. **First masonry course laid on a cement-sand mortar bed
   ("подушка... из песка бетона"), all subsequent courses on adhesive —
   with an explicit numeric mechanism for why, not stated in this page's
   existing first-course-mortar-bed corroboration**: adhesive layer
   thickness is capped at **10mm**; beyond that, the adhesive's finer
   aggregate fraction can settle/subside within the joint and produce a
   crack over time. This independently corroborates the existing
   "first course always on mortar, never adhesive" rule already on this
   page (Zemskov sources) with a second company's practice, **and adds
   the specific 10mm adhesive-thickness ceiling and its settlement
   mechanism**, which the existing content didn't state numerically.

## Planning Rules — Whole-Apartment Pre-Wall Squaring, Crew Structure, Speed

3. **Squaring must be measured/marked for the *entire* apartment before
   wall construction starts, not corrected after the fact** — explicitly
   stated reasoning: discovering later that a corner needs an 8cm plaster
   build-up (or, worse, genuinely can't be corrected) is the failure mode
   this avoids. Independently corroborates this page's existing
   Zemskov-sourced laser-projection whole-apartment squaring/layout
   principle with a second, unrelated company's practice — on this job,
   squareness reference marks are set on day one, before any wall goes
   up.
4. **Modern squaring tooling: laser-based, not a physical set-square** —
   the speaker states the company doesn't even stock an ordinary 90°
   carpenter's square anymore ("мы это уже прошлый век"), though he notes
   a client wanting to verify a corner themselves would typically buy an
   ordinary set square, since it's simple enough for a non-specialist to
   walk around and check any corner with.
5. **Real job-speed/crew-structure data point**: this ~96m² object was
   completed (through full plastering) in **2 weeks**, with a crew of
   six-to-seven (including the speaker). **No unskilled-helper/laborer
   role** — every crew member is described as a fully qualified all-
   round finisher ("универсал"), which the speaker credits for the
   crew's ability to divide tasks in parallel on arrival (some doing
   layout marking, others starting demolition simultaneously) and know
   what to do next once demolition finishes, without needing to re-plan.
   Framed candidly as hard to replicate — requires time, experience, and
   a team that already works together well, not just hiring more people.

## Mistakes / Warnings — Client-Facing QC Verification and Neighbor Noise

6. **Client/independent-inspector-facing QC verification practice**: the
   crew leaves marked reference lines ("провелы отмечены") on walls
   specifically so a client (or the client's own independent building
   inspector, "технадзор") can call in, be told exactly which marks to
   check, and verify wall straightness/squareness themselves against
   those references — a concrete client-verification mechanism distinct
   from this page's existing acceptance-checklist content, which
   describes the crew's own tools/tolerances rather than what's left

   documentation is also required during work specifically at every
   seam between two different materials, to confirm mesh reinforcement
   is actually present, and at the masonry top joint, to confirm it's
   fully foamed — corroborates this page's existing joint-treatment
   content with an explicit documentation-as-proof practice attached.
