## Doors / Trim

- **Old-building opening measurement rule, genuinely new vs. the existing
  Minsk new-build measurement protocol already on the wiki page**: in an
  old building with a poured-concrete door "rebate"/reveal ledge
  ("четверть") still in place, **measure the opening from the inside**,
  not the exterior face — measuring the exterior opening with the
  concrete rebate still present reads too narrow, because that rebate gets
  cut away during installation to match the new frame. Real measured
  opening on this project: **91 cm × 208 cm**. Complements (doesn't
  duplicate) the existing new-build protocol (measure with old casing
  removed, 3-point width / 2-point height) — this is the equivalent rule
  for a different building type (old-fund vs. new-build), where the
  obstruction is a structural concrete rebate rather than removable
  casing.
- **Rebate-removal scope varies by building type**: this project needed
  only a small rebate section cut away; the installers state that older
  Khrushchevka-era buildings typically need the **entire opening widened**,
  not just a small trim — a heavier-scope warning for anyone with an older
  apartment.
- **Install sequence, consistent with but more QA-detailed than the
  existing Minsk new-build note**: cut/remove old door (angle grinder if
  not preserving it) → mark and trim the concrete rebate to the new
  frame's profile → dry-fit the frame, knock back any interference with a
  hammer drill → set frame level (hinge side first, then latch/strike
  side) → clear insulation (mineral wool) from anchor-hole locations →
  drill anchor holes → drive anchors while continuously re-checking the
  frame hasn't shifted off level → hang the door leaf and lubricate hinge
  bearings with silicone grease **before** hanging → install hardware
  (supplied pre-assembled; lock cylinder core also lubricated with
  silicone grease) → cut keys and test in front of the client at handover.
- **Acceptance/QA checks not previously recorded on the wiki page**: the
  gap at the top of the leaf must be **even on both the hinge side and the
  latch side** — an even top gap confirms the frame is level in both
  planes (top and bottom). Leaf-to-frame press fit is checked for play; if
  play exists, a factory-preset **eccentric ("эксцентрик") adjustment** is
  turned via a 4mm hex key to remove it (documented in principle in the
  existing 80-series entry as an "eccentric" feature — this source shows
  the actual field-adjustment procedure). Deadbolts ("ригеля") must engage
  their frame holes with no binding or rattling when the door closes — one
  of the practical signs of a correctly installed frame. After adjustment,
  lock mechanism is greased again to keep the handle/lock action smooth
  and prevent noise, framed as extending lock service life.
- **Foam-fill technique adds a wetting step not in the existing Minsk
  note**: wet the gap with water first (removes anchor-drilling dust and
  improves foam-to-concrete adhesion) before foaming; foam applied in two
  passes, first bead run along the casing edge so foam reaches close to
  the exterior metal casing; a brief wait for expansion to begin before
  fully filling, to avoid overflow; a light water-mist afterward to avoid
  staining the painted interior frame face.
- **Door handover / operating instructions given to the client** — a
  concrete example of a "how to actually use this door" briefing, not
  previously recorded: bottom lock — key inserted horizontally (either
  face), fully seated, turned two full turns (partial retraction after
  one turn, full engagement/retraction after two); top lock — key
  inserted with its marked dot facing down, also two full turns; **always
  press the handle fully down after closing** so the latch fully seats —
  otherwise the lock mechanism operates under tension and the deadbolts
  drag against the frame (this corroborates, with more mechanism detail,
  the existing "always press the door fully shut" maintenance rule already
  on the wiki page from the Minsk new-build source). Night-latch + turn-
  knob mechanism: locking the interior night latch makes the door
  unopenable from outside by any means; the rotating knob ("барашек")
  still opens from outside with a key.
