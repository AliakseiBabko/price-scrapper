## Durable Facts

- **Four lighting categories used in this company's design practice**: (1) primary/main light (основное — chandeliers, track lighting, light panels/lines, fully luminous ceilings) — fills the room to a base illuminance level; (2) secondary/task light (вспомогательное) — illuminates one functional zone only (cooking area, dining table, TV zone), weaker than main, meant to be used *instead of* main light, not simultaneously; (3) decorative/accent light (декоративное) — low-brightness, hidden from direct view, aimed at a specific object; (4) night/standby light (дежурное) — very low power, always dim, aimed downward, for nighttime navigation. `unverified`, single-account taxonomy.
- **Illuminance target**: recommends ≥500 lux for comfortable perception in any room, stated as notably higher than the low minimums given in the (unnamed) building code (СНиП) referenced. `unverified`, single-account practitioner claim — no code citation or lux-meter methodology given.
- **Main-light color temperature**: recommend ~4000K (neutral daylight) for main and secondary light; using warm ~3000K as the *main* light source is called out as a mistake — causes perceived color distortion (whites read as yellow) and a similarly uncomfortable effect to underlit rooms. `unverified`, single-account.
- **Combining multiple main-light fixture types** (e.g., one chandelier + track lighting/magnetic rail/luminous ceiling/light lines) is recommended over adding many chandeliers (visually excessive) or relying on one weak fixture — all combined main-light sources must share the same color temperature, since a visible mismatch when lit together is called both unattractive and uncomfortable for the eyes. `unverified`, single-account.
- **Secondary/task light rules**: must share color temperature with main light (~4000K); the stated most common design mistake is installing *only* secondary/task lighting and omitting main light entirely, since secondary light alone cannot substitute for whole-room illumination. Secondary lighting tied to movable furniture (e.g., a floor lamp beside an armchair) should only be installed if the furniture layout is firmly settled — moving the furniture later can strand the light without a nearby outlet; if layout is uncertain, the speaker recommends skipping this rather than guessing. `unverified`, single-account.
- **Bathroom mirror lighting**: recommend always running a dedicated cable for mirror backlighting, laid during rough-in rather than added later (added later typically means breaking tile to route a cable) — company's stated standard cable spec for this run is 3-core VVGng, 1.5 mm² per conductor. `unverified`/single-account; cable spec is their stated internal practice, not a code citation.
- **Decorative/accent light rules**: warm color temperature (2700–3000K), always hidden from direct view and aimed at an object, used to build a scene/mood (e.g., TV-viewing or pre-sleep relaxation lighting) rather than for general illumination; should not be used in more than roughly one zone per room, or the overall design is described as visually "falling apart" from over-illumination. LED strip is the cheapest/fastest common implementation but produces visible reflected hot-spots near mirrors/glossy surfaces; a diffuser-profile fixture avoids this at roughly 2–3x the cost and is recommended specifically near reflective surfaces. Recessed "look-up-only" accent fixtures (for uplighting plants/statuary/floor compositions) are noted to cost roughly 4x a standard spot fixture of the same class. `unverified`, single-account; the 2-3x and 4x cost multiples are relative claims with no currency/absolute figures given.
- **Night/standby light rules**: very low power, always dim, aimed downward; used continuously or nightly to allow moving between rooms without turning on main lighting; implementations cited: baseboard-integrated LED strip, small wall-mounted near-floor fixtures, or small recessed step lights. Must be present in hallways/corridors/entryways AND in bathrooms/WCs (reasoning: reaching a WC with no night light forces using bright main light, which is jarring at night). Should **not** be installed in bedrooms — reasoning given is it disturbs sleep, and because standby lights across the home are wired to switch together, turning off the bedroom's would darken the rest of the home's standby lighting too; recommend an ordinary bedside lamp instead for personal nighttime light in bedrooms. Stated common mistake among "beginning designers": substituting decorative lighting for night/standby lighting — doesn't work because decorative fixtures across different rooms aren't wired to turn on together the way dedicated standby lighting is. `unverified`, single-account.
