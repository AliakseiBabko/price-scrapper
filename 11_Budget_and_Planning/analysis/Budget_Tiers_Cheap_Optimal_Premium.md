# Budget Tiers: Cheap / Optimal / Premium, Per System

Part of [[11_Budget_and_Planning/Budgeting_Guide|Budgeting Guide]]. Created
2026-08-28 at the user's explicit request for a specific way of organizing
option data: instead of one flat list of materials/techniques per
system, group every system's real options into three tiers — **cheap
(but still quality)**, **optimal**, and **premium/no-compromise** — with
the functional, durability, and customization difference between tiers
stated explicitly, so a reader can consciously choose a tier per system
rather than defaulting to "the best" or "the cheapest" everywhere.

**This project's own stance (per the user, recorded verbatim intent)**:
default to **optimal** across most systems, spend up to **premium**
selectively where the difference is visible/felt daily (the user gave
lighting and flooring as the kind of thing worth this), and treat pure
bottom-tier "cheapest" as something to avoid by default rather than a
starting point. This page documents *what the tiers are*, not this
project's own per-system tier selection — that's a separate decision the
user makes once enough systems are covered here.

## ⚠️ Read this before trusting any tier assignment below

Every tier assignment on this page comes from **one source**: Konstantin
Kruglov, owner of Ontario (a Moscow-region turnkey renovation company),
`Tyl0yPQkO5g` (2025-03-21). Per this project's standing advertising
filter and per the user's own explicit instruction on this source: he is
selling his own company's renovation services, and every tier boundary,
price figure, and "no other winner" judgment below is **his own
professional opinion about where the value sits**, not an independent or
regulatory standard. A different practitioner could draw the cheap/
optimal boundary in a different place, or disagree entirely (e.g. this
vault already has a genuine documented disagreement about floor-taping
between two other practitioners — tier boundaries are exactly the kind
of judgment call likely to vary the same way). Treat this page as **one
practitioner's tiering of the market**, useful as a first structure to
react to, not a settled fact. `single-account` throughout unless another
source is cited.

## Cross-tier coherence: this source's own position, and a caveat the user added

**The source's own explicit closing point** (and the reason this
framework is useful at all): you are not meant to pick one tier and apply
it to your whole apartment. The intended use is picking a tier **per
system** based on your own priorities and budget — e.g. budget doors +
optimal plumbing/flooring + premium ceiling, all in the same apartment.
Nothing in the source itself argues tiers must match across systems.

**The user's own added caveat, worth tracking independently of this
source**: some tier choices carry real *technical* dependencies on other
systems, not just an aesthetic-coherence preference — pairing an
expensive fixture with a bottom-tier system it depends on can be a
functional mismatch, not just a taste question. Concrete examples visible
in this video's own content:
- **Hidden/concealed-mount interior doors** (premium tier, this page's
  Interior Doors section) can require the opening to run floor-to-ceiling
  — that has consequences for the **ceiling system** (which ceiling tier
  and construction method accommodates a floor-to-ceiling door reveal)
  and for **wall finishing** around the frame, not just the door budget
  line.
- **Concealed/built-in mixers** (optimal-and-up tier, this page's
  Plumbing section) need wall depth to embed the valve body — a
  dependency on the wall's own construction, not just a plumbing-fixture
  choice.
- **Epoxy grout** (premium-only per the source) is tied to the **tile
  size/format tier** it's grouting, not an independent choice.
- **Supply-exhaust ventilation** (premium tier) needs ceiling depth for
  ducting — a direct dependency on the **ceiling system's** tier/type,
  which the source itself flags (doesn't fit most old low-ceiling
  "khrushchevka" apartments).

**Practical rule of thumb from this, for this project's own use**: before
locking a premium (or bottom-cheap) choice on one system, check whether
another system it physically touches (ceiling height/type, wall
thickness, floor buildup) needs to move to a compatible tier too — the
user's framing of "an expensive light and a cheap floor in the same room
isn't an option, it's a bad choice" applies most literally where a real
physical/technical dependency exists like the ones above, not to every
possible pairing of unrelated systems.

## Ceiling

- **Cheap (but quality)**: plain matte stretch ceiling, classic harpoon-track
  mounting profile, no added complexity (a named brand example: MSD
  Premium, among others). **A second Kruglov/Ontario source (added
  2026-08-28) corroborates this cheap-tier configuration** (no shadow-gap
  profile, standard decorative insert trim) and adds one mild detail:
  this basic insert can be finished in black for a deliberate style
  accent, not just left in a plain white default. [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_dBn4nhn8d9c_kruglov_budget_stylish_reno_2024|YT_dBn4nhn8d9c]]]
- **Optimal — the source's own "no other winner" pick** for reliability,
  repairability, price, and install speed: the same stretch ceiling, but
  with a **shadow-gap ("теневой") profile** instead of a plain trim.
- **Premium/no-compromise**: drywall (gypsum-board) ceiling — single or
  double layer, hidden niches. Best visual result and customization
  potential; the source names it as every designer's default favorite,
  but does not rank it above the stretch-ceiling option on reliability or
  cost.

## Electrical (rough-in), worked for a 100 m² apartment

- **Point density**: cheap ≈1 outlet/switch point per 2 m² (≥50 points on
  100 m²); optimal ≈1 point per 1 m² (≥100 points); premium ≈1.5 points
  per m² (≥150 points).
- **Device tier**: cheap = plain switches/outlets only (named budget-brand
  example: Legrand Valena), no pass-through/cross switches, no dimmers,
  no smart-home devices. Optimal = pass-through/cross switches added where
  needed, minimal smart-home elements. Premium = fully smart-home
  integrated, expensive switch/hardware lines throughout.

## Wall Finishing

- **Cheap**: plain wallpaper — thicker is better (thinner wallpaper needs
  more substrate prep, raising cost elsewhere), patterned or plain per
  taste.
- **Optimal — a deliberately mixed pair, not one material**: paint-ready
  wallpaper *and* paint, used **in different rooms of the same
  apartment** by design — paint-ready wallpaper (cheaper substrate prep)
  in rooms you're fine not having painted (bedroom, walk-in closet), full
  paint (better look, costlier substrate prep) in rooms where appearance
  matters most (living room, kitchen). Framed explicitly as how to get an
  expensive-looking result in the rooms that matter while saving
  substantially on the rest.
- **Premium/no-compromise**: decorative plaster, wall panels, wood slats
  ("рейки"), microcement, large-format tile-as-wall-cladding, and
  moulding/baguette work (flagged as its own separate hassle — the source
  references a dedicated upcoming video on "walls to Q4 finish standard").

## Tile (floor and wall — the source states these are the only two
material categories that exist for this use)

- **Cheap (but quality)**: porcelain stoneware (керамогранит) only,
  restricted to 20–60 cm per side (20×20, 20×40, 40×60, 30×60, 60×60) —
  cheapest install method and the widest size/price selection on the
  market.
- **Optimal**: large-format porcelain, roughly 60–150 cm (60×120, 80×150,
  80×120, etc.) — materially more design freedom; thin parquet-look tile
  also fits here.
- **Premium/no-compromise**: extra-large-format slabs up to ~3 m long
  ("giant canvases" — expensive, but the source's own studio uses them
  regularly), mosaic, and **epoxy grout** anywhere.
  - **⚠️ Epoxy grout is explicitly never a cheap-tier or general
    optimal-tier choice** — in the optimal tier it is used *only* on a
    tiled shower podium, nowhere else; in the premium tier it can be used
    anywhere. **Concrete price contrast, whole-bathroom example**: cement
    grout for an entire bathroom ≈**$150–$200** (10,000–15,000 RUB) vs.
    epoxy grout for the same bathroom ≈**$1,000–$1,200** (100,000–120,000
    RUB) — roughly a 5–10× material-cost jump before counting that epoxy
    grout installation labor is itself cited as ~5× more expensive than
    cementitious grout installation. (Converted at the trailing-6-month
    mean before the confirmed 2025-03-21 upload date, ≈96.7 RUB/USD.)

## Flooring

- **Cheap, with an explicit caveat**: laminate, or SPC quartz-vinyl — the
  source flags real caution around quartz-vinyl generally (cross-
  references this channel's own dedicated quartz-vinyl explainer) and
  stresses this tier only works with a **genuinely quality** SPC product,
  not the cheapest available.
- **Optimal**: glue-down LVT quartz-vinyl (lower-fuss option) or
  engineered/parquet board on underlay or glued down (more natural-feeling
  option) — the source's own two picks for "least fussy" vs. "more
  natural."
- **Premium/no-compromise**: multi-layer "Rigid" quartz-vinyl (the top
  quartz-vinyl tier), engineered board (called the most natural feeling
  while still reliable), and solid/piece parquet ("штучный паркет," most
  natural of all but with its own real installation complications);
  microcement flooring also fits here.
- **Linoleum is explicitly excluded from all three tiers** — the source
  states he does not consider it a modern material appropriate for a
  quality renovation at any budget.
- **A cheap-tier product-configuration detail, per a second Kruglov/
  Ontario source (added 2026-08-28)**: quartz-vinyl with an integrated/
  attached underlayment (rather than a separately purchased underlay)
  is specifically recommended at this tier — cheaper to install,
  moisture-resistant, heated-floor-compatible, and allows continuous
  large-area runs without transition strips or thresholds, concrete
  enough that the source suggests it can even replace tile in an
  entryway/hallway. [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_dBn4nhn8d9c_kruglov_budget_stylish_reno_2024|YT_dBn4nhn8d9c]]]

## Lighting (added 2026-08-28, single new source — not yet a full three-tier breakdown)

- **Cheap**: track lighting or surface-mounted spotlights, explicitly
  preferred over recessed (встраиваемые) fixtures at this tier — the
  source states recessed lighting is "already leaving the trend."
  A cheap-tier curtain-track-concealment technique: form a hidden
  niche at the stretch-ceiling edge with an integrated ceiling-mounted
  curtain rod, which visually raises perceived ceiling height.
  [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_dBn4nhn8d9c_kruglov_budget_stylish_reno_2024|YT_dBn4nhn8d9c]]]

> [!WARNING]
> **⚠️ Open, unresolved same-channel disagreement on cheap-tier lighting (added 2026-08-28, Round 14 triage)**: `dBn4nhn8d9c` above prefers track lighting or surface-mounted spotlights at the cheap tier, explicitly *over* recessed fixtures ("recessed lighting is already leaving the trend"). A different Kruglov/Ontario video (`mJ0uLdys5cE`) states the opposite for its own cheap-tier package: **surface-mounted or recessed point downlights, or a chandelier** — explicitly *excluding* LED strips, track lighting, and any backlighting at the cheap tier. Both positions come from the same channel; recorded as an open disagreement, not merged or silently favoring either side. [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_mJ0uLdys5cE_kruglov_best_2025_solutions_budget|YT_mJ0uLdys5cE]]]

## Furniture (added 2026-08-28, Round 14 triage — this page's first source on this system)

- **Cheap (but quality)**: fully ready-made, serial/modular furniture
  only — modular kitchen units assemblable from a catalog/marketplace
  rather than custom-fabricated cabinetry, and ready-made wardrobes/
  cabinets/dressers rather than built-in wardrobe systems. Explicitly
  named as a real cost driver worth cutting first when the goal is
  maximum savings — no custom kitchen, no custom built-ins at this tier.
  [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_mJ0uLdys5cE_kruglov_best_2025_solutions_budget|YT_mJ0uLdys5cE]]]

## Baseboard (skirting)

- **Cheap**: PVC baseboard with an integrated cable channel — **quality
  hardware still matters even at this tier**: cheap corner/end fittings
  pop off after minimal contact, and the source explicitly will not go
  below a baseboard with decent fittings even when the goal is maximum
  savings.
- **Optimal**: ready-made MDF baseboard, or a paintable profile (duropolymer
  or polystyrene).
- **Premium/no-compromise**: hidden-mount and shadow-gap baseboards —
  labor-intensive to build correctly but a real, modern, reliable look
  per the source (not just a fragile aesthetic choice).

> [!WARNING]
> **⚠️ A genuine same-channel disagreement on where PVC baseboard sits
> (added 2026-08-28)**: `Tyl0yPQkO5g` above places PVC baseboard at the
> cheap tier and endorses it as fine so long as the hardware/fittings are
> decent quality. A second Kruglov/Ontario source takes a stricter
> position: it recommends avoiding PVC baseboard entirely, stating it
> signals "this is a cheap renovation," and instead starts its own
> "budget-but-not-cheap" recommendation at polyurethane or durapolymer
> paint-ready baseboard — with a further cost-saving fallback to **MDF
> paint-ready baseboard specifically protected by a moisture-proof film/
> coating** (MDF's core weakness being moisture sensitivity) as a
> cheaper-than-polyurethane alternative once that protection is in
> place. It also names a further alternative not on this page at all: a
> plain metal corner/angle trim run along the room perimeter, described
> as a good-looking, inexpensive option distinct from any baseboard
> product. **Recorded as an open, two-sided disagreement, not resolved
> in favor of either position.** [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_dBn4nhn8d9c_kruglov_budget_stylish_reno_2024|YT_dBn4nhn8d9c]]]
>
> **⚠️ A third Kruglov/Ontario source reinforces the MDF/avoid-PVC side
> (added 2026-08-28, Round 14 triage)**: `mJ0uLdys5cE`'s own cheap-tier
> package specifies factory-finished (pre-painted or film-wrapped) MDF
> baseboard, with no PVC baseboard mentioned anywhere in its cheap-tier
> list. This brings the running count to 2 sources favoring MDF/avoid-PVC
> vs. 1 source favoring PVC-at-cheap-tier — worth noting, but a vote
> count isn't new technical evidence, so the disagreement above stays
> open rather than resolved by tally. [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_mJ0uLdys5cE_kruglov_best_2025_solutions_budget|YT_mJ0uLdys5cE]]]

## Window Reveals/Slopes (откосы)

- **Cheap**: plastic (PVC panel or sandwich-panel) reveals with a plastic
  corner bead — **skipping the corner bead is a real crack risk**, even
  though the source's own studio sometimes does this on request.
- **Optimal**: paint-ready reveal (drywall- or plaster-clad, full paint
  prep including fiberglass wallpaper reinforcement) — **a crack can form
  between the plastic window-frame profile and the painted reveal**;
  the source states this happens to some installations and not others,
  without a clean predictor.
- **Premium/no-compromise**: tile (including a single cut piece of
  large-format porcelain), MDF panels, or artificial stone — "any
  material, they'll make it."

## Interior Doors

- **A named budget/space-constrained alternative, with an explicit
  tradeoff (added 2026-08-28)**: when a swing door doesn't fit the
  available space, a sliding door mounted on the wall outside the
  opening is an inexpensive, reasonable-looking alternative — but with
  **zero soundproofing**, a real named tradeoff rather than a free win.
  [source: [[11_Budget_and_Planning/_supporting/knowledge/sources/YT_dBn4nhn8d9c_kruglov_budget_stylish_reno_2024|YT_dBn4nhn8d9c]]]
- **Cheap**: standard external-hinge swing-mount doors, quality
  construction, **≈$150–$200 per set (15,000–20,000 RUB)**.
- **Optimal**: same swing/classic mounting type, **≈$200–$400 per set
  (20,000–40,000 RUB)** — genuinely better hardware and sound
  insulation at this price step, per the source.
- **Premium/no-compromise**: hidden/concealed-mount doors — can run
  floor-to-ceiling, built to arbitrary custom specification —
  **≈$400+ per set (35,000–40,000 RUB and up), commonly reaching
  ≈$1,000+ (100,000+ RUB)**. (Same trailing-6-month conversion basis as
  the tile figures above.)

## Ventilation

- **Cheap (but quality)**: a single air conditioner (bedroom, typically)
  — the source states this is the entire ventilation system at this
  tier, nothing else.
- **Optimal**: AC plus a "бризер" (a fresh-air supply/breather unit) —
  stated to genuinely improve sleep quality and general health, not a
  marginal upgrade (cross-references this channel's own dedicated
  breather-unit explainer).
- **Premium/no-compromise**: full supply-and-exhaust (приточно-вытяжная)
  ventilation — the top of the market, but **explicitly flagged as not
  fitting every apartment**: needs substantial electrical capacity and
  ceiling depth for ducting, and the source states it is impossible in
  roughly 90% of low-ceiling "khrushchevka"-era apartments regardless of
  budget.

## Smart Home

- **Budget package, ≈$10 (1,000 RUB)**: one hub-capable smart speaker
  (named example: a Yandex Station acting as hub) + a door-open sensor on
  the entrance + one vibration sensor on a safe (+ optionally a leak
  sensor) — a minimal but genuinely functional package at this price.
- **Optimal package**: the same hub, plus door-open sensors, safe
  vibration sensor, a **full leak-protection system** (hot/cold water
  supply and heating loop), window vibration/open sensors, at least one
  camera on the entrance zone (auto-recording), and a remotely-activated
  robot vacuum — described as covering security fully (flood protection,
  intrusion/tamper detection) plus basic cleaning automation.
- **Premium/max package**: full smart-home functionality — lighting,
  complete climate control including motorized curtain drives, everything
  from the optimal tier, plus smart appliances (a smart kettle, smart TV,
  etc.), and a dedicated wall-mounted control panel/screen in addition to
  phone-app control.

## Plumbing Fixtures

- **Cheap (but quality)**: bathtub only — acrylic or cast iron, built-in/
  wall-set type, **no structurally-built shower cabin at this tier**;
  countertop or wall-hung sink on a wall-mount or floor-standing cabinet;
  standard floor-standing toilet.
- **Optimal**: bathtub upgraded to cast/cultured marble (pricier, "super
  nice" per the source), **or** a structurally-built shower cabin (a
  ready-made stone pan, or a tiled podium); built-in/concealed mixer
  valves, a thermostatic shower mixer; wall-hung toilet on an installation
  frame; a hygienic shower spray/bidet spray can be added here.
- **Premium/no-compromise**: a freestanding bathtub; if a shower cabin,
  only the structurally-built version, with an **epoxy-grouted** podium
  (ties back to the Tile section's epoxy-grout rule); mostly
  external/exposed designer mixers on sink and shower, or an external
  floor-standing mixer for a freestanding tub (sometimes needing a custom
  aluminum-profile box to conceal supply piping); expensive designer sinks
  (marble, artificial stone, any shape); smart toilets, either a fully
  smart integrated system or a plain expensive wall-hung toilet paired
  with a smart bidet seat/lid.
