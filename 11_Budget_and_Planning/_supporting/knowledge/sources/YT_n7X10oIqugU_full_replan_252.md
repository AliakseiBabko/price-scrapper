## Rules / Heuristics — Developer Defects Documented

- **A developer-left entrance vestibule only 54cm wide is too narrow for any real coat-storage closet** — the maximum closet depth achievable in that space was only 46cm, and even that conflicted with the door opening. General caution: verify vestibule width against real closet-depth needs before accepting a developer's entrance layout.
- **⚠️ A closet/storage niche can also be built *too deep*, not just too shallow** — a documented developer defect: a 1.10m-deep niche for a coat closet, when a standard hanging-storage zone only needs 600mm of depth (doors typically mount flush with that plane) — the remaining ~50cm is simply wasted floor area, not usable storage. Complements this store's already-extensive too-shallow-niche corroboration chain with the opposite failure mode.
- **A walk-in closet ("гардеробная") can be built with a wide, easy-to-use double-door entry but almost no real interior storage** — documented case: 1.10m-wide entry, but only 65.5cm of interior depth, yielding two small storage cubbies (65×60cm and 65×40cm) — described sarcastically as barely large enough for two coffins standing upright. A wide entry alone is not evidence of a functional walk-in; check the actual interior storage-zone dimensions independently.
- **⚠️ Always positively identify what an exposed/protruding pipe or riser actually is and does before finalizing a design around it** — a real documented case: one bathroom's exposed riser carried hot water only, with no cold-water riser present at all (later patched with a mismatched polypropylene pipe); a second bathroom had an unidentified pipe running floor-to-ceiling that even the developer apparently couldn't explain. Don't assume a protruding pipe's function from its position alone.

## Rules / Heuristics — Redesign Techniques

- **⚠️ Wall-alignment technique at a broken/interrupted wall run**: when a wall run is split by an obstruction (e.g. a ventilation shaft gap) into two segments, build both segments flush to one shared reference plane rather than overlapping or independently offsetting either segment ("внакладку") — avoids downstream alignment problems. General planning discipline for any wall run broken by a fixed obstruction.
- **A non-load-bearing 100mm partition built directly alongside a ventilation shaft or load-bearing wall specifically to avoid needing to chase (штробить) electrical into the shaft/load-bearing wall itself** — a concrete workaround technique reinforcing this store's existing "never touch a venshakhta" rule: rather than avoiding electrical near the shaft entirely, build a thin dedicated partition next to it and run wiring there instead.

- **⚠️ Nuance to this store's well-established 150mm soundproofing-partition figure**: when a full-depth closet run is built directly against a partition wall, the closet itself already provides more sound isolation than a bare 150mm partition would — so in that specific configuration, the partition can be reduced to 100mm without a net soundproofing loss, and the reclaimed 50mm can go toward a wider closet or a shifted door instead. **This qualifies, not contradicts, the 150mm default**: it only applies when a full closet run directly backs the partition for its whole length, not as a general excuse to thin every partition.
