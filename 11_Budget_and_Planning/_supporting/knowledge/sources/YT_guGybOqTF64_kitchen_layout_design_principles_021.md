## Rooms / Zones — Kitchen

- **Never cut into a load-bearing wall to route plumbing/electrical for a
  kitchen wall run — build a furring/false wall out from it instead**,
  never chase the load-bearing wall itself or disturb its internal
  rebar. Real worked example: a 50mm furring wall built specifically to
  route sink/dishwasher/washing-machine plumbing along a load-bearing
  wall.
- **Standard-module-sizing rule**: default every kitchen cabinet module
  to standard widths (40/50/60cm etc.) rather than custom sizes — custom
  modules (e.g. 537mm, 649mm) typically carry a real cost premium, and
  standard modules integrate more reliably with built-in appliances sized
  for them. **Practical technique to hit this even in an oddly-sized
  run**: make only the *last* module in a run custom-sized (grown or
  shrunk) so every other module can stay a round 5cm/10cm multiple, or
  use a plain filler/spacer strip (see below) instead of resizing a
  functional cabinet.
- **Filler-strip technique, two concrete uses in this project**: (1)
  between the fridge and an adjacent wall, sized so the fridge sits far
  enough out that its door swings a full 90-95° without hitting a nearby
  window-sill overhang (this project's sill overhang: 40mm) — also
  eliminates a dead unreachable gap behind the fridge that otherwise
  becomes a "bag of bags" (accumulated stray plastic bags), flagged as a
  real modern-renovation faux pas worth designing out; (2) a narrow
  pull-out filler strip next to the cooktop, used to store cooking oil
  and similar items, doubling as a buffer preventing heat/vibration
  interaction between the cooktop and an adjacent appliance — **some
  kitchen-cabinet manufacturers require a minimum gap between a cooktop
  and any adjacent module**, so including this strip by default keeps a
  layout compatible with more manufacturers' specs, not just one.
- **Tall-unit (fridge/oven column) placement rationale**: place the
  tall fridge/oven column at the end of the run nearest existing natural
  light (a window), not mid-run — a tall unit placed where the main
  prep/cooking zone would otherwise be casts a shadow over that zone,
  degrading natural light there; placing the tall unit itself in the
  shadowed position "sacrifices" a unit that doesn't need good lighting
  as much as a countertop workspace does. A tall unit placed mid-run is
  also flagged as visually disruptive to the kitchen's overall look.
- **Wet-appliance clustering rule**: place all plumbing-dependent
  appliances (sink, dishwasher, washing machine) as close to the riser/
  stack as practical; place the fridge and any tall column (neither
  needs water/drain) at the *far* end from the riser instead — minimizes
  plumbing run length/complexity for the appliances that actually need
  it.
- **Washing machine placed at the run's far end, away from the main
  cooking zone** — explicit reasoning: laundry-related activity (loading
  detergent, handling dirty laundry) is undesirable directly in the
  primary food-prep area, so it's positioned to minimize overlap with
  active kitchen use.
- **Oven placement, current standard practice per this source**: where
  kitchen dimensions allow, place the oven in a tall column, elevated
  above floor level (not under the cooktop) for easier use without
  bending down.
- **Microwave placement principle, with an explicit corrected mental
  model**: many assume people load the microwave directly from the
  fridge — the source states the real sequence is fridge → plate/
  countertop → microwave → back to fridge (or eaten), so **a microwave
  needs adjacent countertop space to interact with, not fridge
  proximity** as the driving placement factor.
- **Dishwasher-side-of-sink rule tied to the *specific client's* stated
  hand preference, not assumed handedness**: ask the client directly
  which hand they use to hold a dish while scraping food waste into the
  sink/bin before loading the dishwasher — that same hand determines
  which side the dishwasher should sit on (this project's client: holds
  dishes in the left hand → dishwasher placed to the left of the sink).
  **Corroborates this store's existing dishwasher-placement rule**
  (`yt_RDOUfxTW2sA`, which assumed general right-handed ergonomics) with
  a more careful client-specific-preference framing rather than a
  universal handedness assumption.
- **Additional layout micro-rules stated**: cutlery drawer positioned
  near the dishwasher (not open utensil rail, by this client's
  preference); large pot/pan drawers positioned near the stove; upper
  cabinet height/module choice is treated as unconstrained client
  preference (no electrical/plumbing dependency, unlike lower cabinets);
  designer's one mandatory obligation for upper cabinets is ensuring
  task lighting is planned for the prep zone beneath them.
- **Primary vs. secondary cooking-zone definition, with reasoning**: the
  primary/main prep-and-cook zone is defined as the counter run *between*
  the sink and the cooktop (where most hands-on food prep happens);
  zones outside that span are secondary, and are the appropriate place
  to put "parking spot" storage for small appliances used occasionally
  (e.g. a meat grinder stored in a drawer when not in use) or a
  permanently-plugged-in small appliance used constantly (e.g. a coffee
  machine kept out on a dedicated "parking" countertop spot).
  **Corroborates and refines this store's existing "maximize the sink-to-
  cooktop zone" heuristic** (`yt_UoqC7xSFZ4Q`) by explicitly naming it the
  primary zone and defining what belongs in the secondary zone instead.
- **Twin-fridge space/cost trick**: for a very wide fridge footprint
  (this project's example: ~1.2m), install two ordinary standard-width
  (~60cm) fridges side-by-side facing each other, instead of buying one
  wide built-in unit of the same total width — **claimed significantly
  cheaper than a single large built-in fridge**, with the added benefit
  that if one unit fails, the other still functions as a partial backup,
  reducing total food-loss risk. `single-account`, `unverified` relative
  cost claim (no absolute figures given), but a genuinely new, concrete,
  checkable space/appliance-selection trick.
