## Furniture / Built-ins — Durable Facts & Rules

- **For a narrow (~1.05m-wide) storage room, an L-shaped or single-run storage layout fails arithmetically** — after accounting for the minimum 70cm rough door opening plus trim standoff, only ~25-35cm of width remains for a storage zone on the far side, too shallow for hanging clothes and barely usable even for shelving (60-80cm shelves would consume most of the walk space). **Do not attempt this layout.** `confirmed`, worked arithmetic.
- **A layout with storage along the back wall (facing the entry) also fails** for the same room — a 600mm walk aisle is needed for comfortable movement, leaving only ~45cm for the back storage zone, again too shallow to hang clothes properly. `confirmed`.
- **The only workable layout for this exact room shape**: **60cm storage zones on both left and right walls, with a shallow shoe rack (обувница, ~33cm deep) centered at the far end** — this uses the width efficiently (most of the footprint is actual storage, not walk-only aisle) and avoids "dead corners" that a three-sided layout would otherwise create. `confirmed`, arithmetic-verified as the only layout that fits.
- **Vertical zoning (same 3-tier logic as `RyHzFDGgqKA`)**: bottom 50cm for shoe boxes, 50cm-to-~2m/210cm for hanging clothes (shoe rack height matches the clothing-zone top), above that a mezzanine for a home network shelf (router, NAS, active network switch, spare outlets for future devices) and 2-3 stored suitcases. `confirmed`.
- **Practical tip**: thickening one side wall by 10cm (at the cost of negligible storage-zone depth) creates room to embed a recessed electrical panel (щиток) inside that wall — cited as done on a real project. `confirmed`, real example.
