- **Market availability ranking**: classic hinged doors have by far the largest number of models on the market; sliding-pocket and concealed-mount are roughly tied for a distant second/third — both meaningfully scarcer than classic hinged. `confirmed`, speaker's stated market observation (unverified against external catalog data).
- **Door+hardware set price floor by type (RUB, materials/hardware only, excl. installation)**: classic hinged from ~10,000 RUB/set (up to 30,000–40,000 RUB); sliding-pocket from ~20,000 RUB/set (pocket cassette itself adds meaningfully if bought pre-made); concealed-mount from ~30,000 RUB/set for a full kit (embedded frame, leaf, hardware). `confirmed`, directly stated ranges.
- **Installation cost is the real differentiator, not the door price alone**: classic hinged full turnkey install (hinge/lock mortising through casing installation) ≈5,000 RUB/door regardless of telescopic or standard trim choice. Concealed-mount installation is described as disproportionately more expensive and complex: base structural install (frame, concealed hinges, lock) ≈7,000–10,000 RUB, **plus** two-sided painting (~5,000–6,000 RUB), **plus** sealing the flush-mounted-side wall-to-frame seam (~5,000–7,000 RUB, described as skilled/painstaking finish work), **plus** the exposed-reveal side needing full window-reveal-style finishing (plaster, putty, fiberglass mesh, finish putty, primers — ~7,000 RUB). **Total concealed-door install commonly reaches ~30,000 RUB** — i.e. roughly matching the door's own material cost, making the effective per-door cost ~2x what the sticker/material price alone suggests. `confirmed`, concrete itemized breakdown — the most granular concealed-door cost breakdown in this store to date.
- **A concealed door commonly implies a matching concealed/shadow-gap baseboard (теневой плинтус)** in the same room by default (design convention), which is a further, separate budget line the client should anticipate — not counted in the above door-only totals. `confirmed`, corroborates and extends the existing store's baseboard-cost-driver material already present.
- **Soundproofing**: classic hinged and concealed-mount doors can both achieve good soundproofing (depends on leaf construction/seal quality, ask the retailer specifically) — sliding-pocket is the clear outlier/worst performer, because the leaf is only anchored at the top rail; there is essentially no seal at the sides, bottom, or rear when closed. Recommends caution using sliding-pocket doors specifically in bathrooms/WC, bedrooms, and (for some clients) studies. `confirmed`, corroborates the existing store fact (from yt_1YiVgB9jqyU) about sliding-door soundproofing being worse — **second independent source now confirming this**.
- **Durability/longevity weak point — sliding-pocket doors specifically**: the mechanical opening-limiter/stopper inside the pocket cavity is a fragile point that's awkward to reach and repair once damaged (leaf width 80–90 cm inside a narrow cavity); some models require a wall access hatch (лючок) to be planned in for future service. Both classic-mount types (hinged, concealed) are otherwise durable if built from quality materials — speaker states well-made doors can last 20–30 years. `confirmed`, corroborates the existing store's sliding-door mechanism-failure fact (yt_1YiVgB9jqyU) with a different specific failure point (opening-limiter vs. rollers/dampers) — a second, complementary mechanism, not a duplicate.
- **Customization/add-on ceiling is far higher for concealed-mount doors**: finish options (glass, metal, wood veneer, structured panel, paint-ready), hardware (concealed hinges, magnetic strikes, concealed handles), non-standard heights (up to 3–4 m, limited only by manufacturer capability) and enhanced soundproofing add-ons (upgraded seals, in-leaf sound damping, and a rising/drop-down acoustic threshold) are essentially unique to this category — classic hinged and sliding-pocket doors have a comparatively limited, standard add-on set (soft-close dampers, opening limiters, magnetic concealed locks). `confirmed`, speaker's stated framework.
