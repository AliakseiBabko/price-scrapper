## Design Concept — Style Consistency Rules

- **⚠️ Rule 1 — one shared base style set (up to 2-3 mixed styles) must run through every room, with a closed-door exception**: you may mix multiple styles (e.g. minimalism + japandi + mid-century, framed as "styles within the same broader style group" that can be freely combined), and different rooms can emphasize different members of that mixed set (a living room using all three, a bedroom using only two, a kids' room using two different ones) — but the *same underlying style set* must be the throughline from room to room. **The only clean exception**: a fully separate, permanently closed-door room (the speaker's own example: her husband's home office, done in a completely unrelated style) — explicitly framed as a deliberate compromise for a family member's preference, not a design best-practice, and noted that homes with one wildly-mismatched room essentially never appear in "showcase" interior-design publications for this reason.
- **Kids-room theme-layer technique**: within the shared base style, a kids' room can add a distinct *theme* on top (e.g. a superhero theme for a son, a princess theme for a daughter) while the underlying style (e.g. minimalism) still matches the rest of the home — a way to satisfy a child's specific preference without breaking the whole-home style throughline.
- **⚠️ Bold/maximalist-style exception, explicitly named**: styles built around deliberate color/style chaos (Pop Art, Memphis, kitsch-adjacent styles) are explicitly exempted from these consistency rules — for those styles, a "firework of colors" with a different bold wall color in every room *is* the correct execution, not a mistake to correct.

## Design Concept — Color Consistency Rules

- **⚠️ Public-zone vs. private-zone color distinction, a genuinely new framing not on this page yet**: the *base/primary* color palette must be consistent specifically across "public zone" rooms — kitchen, living room, hallway/entry — defined as the rooms guests actually see and where doors stay open; small color *accents* (e.g. bright green curtains/chairs in the kitchen, bright blue pillows/art in the living room) can vary room to room within that same base palette without breaking cohesion. **Private rooms (kids' rooms especially, sometimes bedroom/study) are the explicit exception** where a child's stated color preference should be accommodated even if it breaks the base palette.
- **Same principle extended to flooring**: one flooring material/finish should run through every room, **with kitchen and entry hall specifically exempted if they're tiled** (tile is treated as an acceptable functional deviation from whole-home flooring continuity) — a more specific, named exception than this page's existing "one continuous flooring" technique states.
- **Same principle extended to wall color, again scoped to the public zone**: kitchen, living room, hallway/entry should share the same wall color (or at minimum stay within the same color family/palette); private rooms may deviate more, but the recommendation is still to stay within the same overall palette rather than a fully unrelated color — "if you truly want something completely different, keep that door closed" (ties back to Rule 1's closed-door exception).

## Design Concept — Connective-Decor Technique (conditional, not always needed)

- **⚠️ Repeating specific decor objects as an explicit fallback technique, conditional on wanting per-room style/color variation**: when a household deliberately wants each room to feel *somewhat* different in style or color (rather than one uniform look everywhere), repeating specific decor elements room to room is the recommended connective technique — named examples: paintings by the same artist appearing in multiple rooms, curtains matched to wall color repeated across rooms, decorative vases/sculptural pieces from a favorite artist repeated across rooms. **Explicitly stated as unnecessary if a household instead chooses one uniform style and palette for the whole home** — a conditional technique, not a universal requirement, distinct from how Anuta Vlady's repetition techniques are framed as universally useful regardless of how similar or different the rooms are.
