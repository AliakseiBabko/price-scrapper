**⚠️ Wall-hung toilet on an installation frame only actually saves space
when it reuses an existing santekhkorob (plumbing chase) — a real,
previously unrecorded caveat on this store's existing installation-
frame content**: if the frame is built into a plumbing chase that
already exists for other reasons (water distribution, meters, a
tankless heater), there's no additional wall build-out needed and the
space savings versus a floor-standing toilet are real. But if a new
chase/box has to be built specifically to house the frame, that build-
out consumes floor space of its own — potentially erasing the space
advantage a wall-hung toilet is usually assumed to provide. This store's
existing installation-frame content covers load rating, code-enforcement
risk, and placement conflicts, but not this specific
space-savings-conditional-on-reuse caveat.

**A concrete capacity-mismatch figure for combined washer-dryer units,
