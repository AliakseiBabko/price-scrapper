3. **Island height should always match the main counter run (no bar-stool-height option)**

4. **Island knee-recess overhang, a close but distinct figure from this store's existing
   35-40cm knee-recess rule**: this source specifies **30cm** of overhang on the side facing
   the living/guest zone, with pull-out/hinged storage drawers on the opposite side.
5. **⚠️ No-upper-cabinets-to-ceiling stretch-ceiling integration technique**: when
   cabinetry runs floor-to-ceiling (mezzanine tier flush with the main upper run, per this
   store's existing depth-flush rule), embed a trim/mounting profile into the top of the
   cabinet run at the design stage so a later-installed stretch ceiling membrane meets that
   profile with **zero visible gap** — contrasted with a real-project case in the same video
   where a plain drywall ceiling was used instead and left a visible, unplanned gap because
   this coordination wasn't done in advance.
6. **Full-height pantry-column storage extending into an adjoining bedroom-facing wall** —
   a real-project detail: where a kitchen open-plans into a bedroom corridor, the
   transition wall itself is built out as additional pantry-column storage rather than left
   as a plain partition.
7. **⚠️ Microwave door-swing-side coordination rule, extending this store's existing
   fridge-door-swing-side content to microwaves specifically**: most microwaves hinge on
   the left by default — check the swing direction against your actual kitchen workflow
   (e.g. the fridge-to-microwave carry path) before finalizing appliance placement, and
   mirror the layout (swap fridge/sink positions if needed) rather than accepting an
   awkward door-swing direction.
8. **⚠️ Genuine disagreement — combining oven and microwave into one integrated unit**:
   this source recommends **against** combining oven and microwave into a single integrated
   appliance — a combined unit costs more, and if either function fails, you may lose the

10. **Dishwasher-to-sink proximity rule, a specific constraint**: the dishwasher should sit
