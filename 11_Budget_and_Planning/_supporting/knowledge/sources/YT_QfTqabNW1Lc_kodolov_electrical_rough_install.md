## Switches / Sockets / Cables — New/Extended Detail

- **⚠️ Reflected wall-elevation drawings (развертки) exist specifically so
  a future picture/shelf can be hung without hitting a wire**: if a design
  project documents the socket/switch layout with wall elevations, the
  wire path from any given outlet runs straight up or down at exactly 90°
  — so a homeowner years later can predict "there's a wire directly above
  this outlet" and avoid drilling into it. A concrete, checkable mechanism
  behind "always keep your design-project drawings," not just a vague
  "you'll want them later."
- **"No junction boxes, one breaker per outlet" flagged as a Moscow
  ultra-premium trend with no functional benefit** — tier-steering/mistake
  warning: wiring one dedicated circuit breaker straight to one single
  outlet (skipping the standard branching junction-box topology) is
  presented by some installers as a premium feature but "carries no
  functional benefit" per this source — flag as a cost-inflating pattern
  to watch for, not a real technical upgrade.
- **Back-box (подрозетник) selection criteria, with a real price range**:
  15–250 RUB per unit; a more expensive back-box is easier to install
  precisely and physically holds cable/connections better. Selection
  should weigh wall material and thickness, available recess depth,
  humidity, whether grounding contacts are needed, and whether the point
  needs frequent access (a covered/lidded back-box variant exists for that
  case, framed as rarely actually needed in practice).
- **Rough-stage back-box alignment is the real leverage point for a clean
  finish install**: back-boxes must be set exactly in line (level-checked)
  during the rough electrical stage — a finish electrician then simply
  clips frames on with no correction needed. Sequencing implication: put
  your best/most experienced electrician on the **rough** stage, not the
  finish stage, since a bad rough alignment can't be fixed later by a
  skilled finisher snapping on plates.
- **Switch-side placement rule, adds to this vault's existing 90cm/15cm
  rule**: position the switch on the same side the door opens toward (the
  handle side), so it can be found and pressed without looking — the
  existing page already has the 90cm height / 15cm-from-opening-edge
  figures but not which side.
- **Living-room general socket spacing heuristic: roughly every 2-3m along
  the walls** as a rule of thumb distinct from the room's fixed-point
  sockets (TV, appliances).
- **"When debating a socket count, round up" heuristic**: if deciding
  between e.g. 2 vs 3 outlets at a location, install 4 instead — framed as
  a near-universal experience that occupants end up wanting more than
  originally planned, not a location-specific formula.
- **Audio/video/computer equipment outlets should be physically grouped at
  one location** to avoid needing extension cords/power strips later.
- **Distribution-panel placement nuance for larger buildings**: for a
  large house/building, the main panel doesn't have to sit in an entry
  closet — it can be placed mid-building in a dedicated small utility/
  patch room ("кроссовая"), from which wiring fans out more efficiently
  than routing everything back to a single entry-point closet. (The
  entry-closet placement itself, ventilation requirement, and no-water/
  no-direct-sunlight rule already exist on this vault's pages —
  corroboration, not new.)

## Regulations / Permits / Approvals — Perspectives (flag, don't resolve)

- **⚠️ Counter-perspective on GOST vs. TU (ТУ) that partially conflicts
  with this vault's existing cable-buying rule**: this vault's
