## Planning Rules — Wall Erection Step-Sequence Methodology

- **Core sequencing rule, stated as the single most important technique in the video**: lay out and erect the first course *ignoring future door openings entirely* — build continuous walls straight through where a doorway will later go, then cut the opening out afterward with a reciprocating saw or hand saw once the wall is standing. Reasoning: cutting an opening out of an already-built, already-straight wall is faster and more accurate than trying to build two independently-plumb wall stubs flanking a pre-planned gap. Corroborates this store's existing opening-cutout-sequencing content from `yt_OR0Vk7V6zeo` (Walls_and_Paint.md), independently on a different project type and two years earlier.
- **Hard-dimension vs. flexible-dimension room planning, explicit methodology (not just terminology)**: distinguish rooms/dimensions where the exact final size is load-bearing for fixture fit (worked example: a 1800mm bathtub — even 50mm short and it physically won't fit, forcing a redo) from rooms/dimensions that can safely absorb accumulated layout error (worked example: a corridor being 2200mm vs. 2250mm is inconsequential). **Practical rule: never try to hold every dimension on a floor plan to spec** — a plan showing "nominal" room sizes for every space is explicitly called a trap if used as the literal build reference, because plaster thickness and small measurement variances make holding all dimensions simultaneously impossible; instead, sequence wall construction so the load-bearing dimensions are locked first (working step-by-step from a fixed reference wall), and let the remaining "flexible" spaces absorb whatever variance results. This is the same hard/flexible framing independently present in this same chunk's `yt_Eq0kg2hD-Ws` — two-source corroboration.
- **Stack/riser lean-compensation technique before framing a duct-concealment box**: before building a wall segment that will define one edge of a future duct/pipe-riser concealment box, measure the riser's own plumb deviation with a dedicated plumb-detection tool (a laser plumb-bob device) to find its *most protruding point* at any height — then reference the wall layout to that most-protruding point, not to the riser's position at floor level. Explicit failure mode if skipped: a riser leaning inward by e.g. 50mm somewhere up its height will collide with a concealment box built from a floor-level reference, forcing the whole corridor width to be reduced to clear it. `confirmed`, genuinely new pre-framing QC step for this store — extends the existing floor/level-survey content (screed zero-reference sources) into a vertical/riser-plumb-survey equivalent for chase/duct-box planning specifically.
- **Block-laying-by-eye tolerance claim**: the source lays block courses by eye (not checking each block individually against a laser level), citing an experienced installer's own visual accuracy as within 2-3mm — justified because blocks are laid under a 5mm plastering-tolerance allowance anyway, so sub-5mm eye-judged error is immaterial once plastered. Explicitly re-checked against a laser level on-camera as a self-audit ("so no one says I'm lying"). `single-account`, an experienced-installer skill claim, not a technique any DIYer should assume transfers without their own practice/verification.
- **Step-by-step numbered-wall project-document convention, reiterated**: a properly usable construction project must present wall/partition erection as an explicit numbered sequence with point-to-point dimension call-outs from a fixed reference at each step — a "nominal room dimensions" summary table (present even in high-end design projects) is explicitly *not* sufficient as a build reference and should only be used for material-quantity estimation, never for laying out walls directly. Reinforces (does not add new numeric content to) this store's existing project-quality-differentiator content.
