- **A concealed-toilet installation (wall-hung, in-wall cistern) requires a dedicated false wall to house the cistern/mechanism and route the water-supply connection point — a step some designs simply omit**, leaving the toilet undeliverable as drawn. Corroborates this store's existing built-in-fixture-wall-thickness caution from other Category 5 sources.
- **A bathroom sink's drawn width can be trimmed down for wall-buildup/tile-thickness tolerance without becoming impractically small** — the source reduces a sink from a larger drawn size down to a final 90cm width to accommodate wall-leveling material and tile+adhesive thickness, and states 90cm remains "quite worthy and ergonomic" — a usable minimum data point for bathroom sink width once buildup tolerance is accounted for.
- **A washer/dryer utility column should be placed as close as possible to the plumbing stack, not just anywhere convenient, specifically so its drain line has a correct slope/fall into the stack** — a defect found placed the column far from the stack, and every closer alternative location conflicted with either being in a bedroom (not a wet/utility space) or blocking normal room use.
- **A shared laundry column placed inside a private room (e.g. a home office) forces anyone doing laundry to enter and disturb the room's occupant** — the source's replan corrects this by moving the column to a shared corridor/hallway location precisely so any household member can use it without needing to enter someone else's private space.
- **A kitchen's corner/sink module should be placed at the plumbing stack location, not chosen freely from the counter run** — reiterated here as the deciding factor for where a corner kitchen module can go, consistent with the plumbing-first sequencing already established in this store.
- **A dishware display shelf/cabinet intended as a visual feature should be checked for sightline from the sofa, not just for fitting somewhere in the room** — a defect found placed the display shelf out of view from the seating area, defeating its stated purpose (the client wanted to see the displayed dishware while seated); the replan repositions it opposite the sofa specifically to restore that sightline.
- **A load-bearing wall's true purpose for a given thickness/protrusion should be interrogated, not assumed** — the source notes an unusually thick wall segment with no clear structural or service reason and treats it as un-diagnosed evidence of a poor original design decision, rather than accepting it as given.
