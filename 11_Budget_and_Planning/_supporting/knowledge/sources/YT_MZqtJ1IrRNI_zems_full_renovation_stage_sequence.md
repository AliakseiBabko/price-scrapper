## Planning Rules — Durable Facts & Rules

Full ordered stage sequence (condensed to the sequencing decisions): design project approval → site prep (temp utilities, consumables) → demolition (walls/openings) → balcony/loggia glazing prep (before window measurer visit, avoids a repeat paid visit) → entrance-door + balcony-window measurement in parallel (both ~10 days lead time, unaffected by dusty demolition happening concurrently) → riser shutoff date coordination for radiator swap → ceiling priming/painting (specifically required before a stretch/fabric ceiling, so neighbor-vibration debris doesn't later fall onto the membrane) → client locks all finish-material choices, **critically including the specific kitchen-cabinet company** (each kitchen manufacturer has its own surface-prep/blocking/outlet-placement requirements fed back to the designer before framing) → wall/partition construction in parallel → AC installer/equipment selection → bathroom waterproofing + screed-beacon leveling (waterproofing must happen right before screed pour if required by the management company) → whole-apartment bonding-primer pass before screed → entrance door/windows/balcony glazing installed before screed pour → AC installer chalks refrigerant-line routing before screed → security/CCTV/satellite/ISP specialists visit before screed to mark cabling requirements, with an explicit rule to **route all their cabling through the main electrician's single pass rather than each vendor separately (~10x cheaper, per source's own unverified estimate)** → screed pour (**WC/bathroom floor finishes 5 cm lower than the rest of the apartment**) → radiators swapped once screed is walkable → second, detailed kitchen-installer site visit (updates project so client never redlines by hand) → rough electrical + rough plumbing → **AC refrigerant-line routing immediately after rough electrical** → underfloor heating (wet rooms) + low-voltage cabling → **false walls for radiator-riser concealment built only after AC line-routing, since both share the same exterior wall path and building the false wall first forces reopening it** → boxes/soffits for risers and furniture load-bearing inserts → priming/corner-bead/skim-coat (two passes) to near-white flat walls → stretch-ceiling measurer called only once walls reach this stage → loggia/balcony finishing deferred until after wall-sanding (dust risk) → bathroom toilet in-wall frame mounted, then tiled → self-leveling compound over the whole-apartment screed → window sills + insulated window slopes → laminate/parquet underlayment → wallpapering/painting → **stretch ceiling installed before flooring** (reversing this order was linked to repeated real damage to finished floors from overhead ceiling work) → doors/arch casings/entrance-door slopes → **baseboards installed only after kitchen and built-in furniture are assembled** (common misconception is baseboards right after doors — baseboards must fit against both door casings and furniture) → finish electrical + AC indoor-unit covers → **finish plumbing, especially the toilet, installed dead last before handover** (stated rationale: most clients don't want anyone else using their new toilet) → final clean + decorative sealant. "Good companies" go further post-handover: hanging accessories/art, delivering/assembling furniture, configuring internet/satellite TV/security. `confirmed`, single practitioner's stated standard sequence, specific and checkable throughout.
