   cups ("присоски")**: for tile this thin/large, lifting it by hand at the
   corners risks cracking it during transfer/carrying, so the crew built a
   dedicated frame ("приспособление") of pipes fitted with suction cups
   specifically to move the slab from cutting table to installation point
   without hand-gripping the edges.
2. **Named format and thickness this technique applies to**: tile format
   **280×120cm, only 6mm thick** — thin enough that hand-carrying by the
   corners has "a very high probability" of the slab cracking in transit or
   during laying. `single-account`, no independent verification.

   is moved into place** — the source calls it "система СВП" (elsewhere in
   this store spelled "СПБ"/SVP tile-leveling-clip system, see
   [[07_Bathroom/analysis/Tile_Selection_and_Layout.md]]) and notes it's set
   up **before** the tile transfer, not after — a small sequencing detail
   not previously on this page.
4. **Substrate prep and full double-buttering rule, stated as a named
   common mistake**: before laying, the screed must be primed with a
   deep-penetration primer ("грунтовка глубокого проникновения") specifically
   to ensure good adhesion with the tile adhesive; the primer used dries
   quickly. **⚠️ The tile must never be laid "dry" onto the floor** — both
   the floor *and* the back of the tile itself must be coated with
   adhesive, not just the floor. The source explicitly flags that "many
   neglect this technology" and lay tile straight onto the floor without
   buttering the tile's own back — calling this **incorrect because it
   leaves voids, degrading installation quality**. This corroborates (from
   an independent channel) the existing store's "double-sided
   buttering above a size threshold" rule already documented in
   [[07_Bathroom/analysis/Tile_Selection_and_Layout.md]] (Kruglov/Ontario:
   any floor tile over 60×60cm needs adhesive on both the substrate and the
   tile's own back) — here stated as a universal rule rather than
   size-gated, for tile at the very large end (280×120cm) specifically.
