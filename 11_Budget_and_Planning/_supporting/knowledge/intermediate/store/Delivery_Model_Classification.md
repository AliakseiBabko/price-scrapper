## Renovation Delivery Model Classification

Per explicit user guidance: this project's own plan is **self-managed /
piecemeal** (hiring individual specialists per trade, sourcing materials
directly), not **turnkey / full-service** (one company bundles design,
management, and construction into one priced package). These produce
genuinely different $/m² figures for comparable underlying work — a
turnkey price includes management/design/coordination overhead a
self-managed budget doesn't pay for. Every cost-bearing source/case in
this store is classified below so figures are never blended across
delivery models.

- **Minsk World 60 m² case** (`dfc91747`/`26bc9c25`, $54,000 / $900/m²) —
  **Turnkey / Full-Service**. Explicitly a "Turnkey Designer Apartment"
  project: custom millwork, furniture, electronics, and full finishing
  bundled into one project total.
- **44 m² Minsk labor смета** (`b385361e`, see
  [[11_Budget_and_Planning/_supporting/case_studies/price_table_screenshot_case|Price Table Screenshot Case]]) —
  **Self-Managed / Itemized, Labor-Only**. The presenter explicitly
  describes the `Цена` column as **average market rate** (not
  premium, not cheapest) for individually-priced work items, materials
  tracked separately, no company-management overhead bundled in. **This
  is the closest comparable dataset in this store to this project's own
  planned approach** — see the rate-card table already in that case
  study ("Companion Benchmark" section) for concrete per-item USD/BYN
  rates.
- **7komnat.by Novaya Borovaya 52 m² case** (`yt_jAdRyL6KFxs`, $70,000 /
  $1,346/m²) — **Turnkey / Full-Service**. The company's own case study
  of its own director's apartment; the four budget groups explicitly
  bundle design, approvals, all labor, and all furniture/appliances into
  one company-managed total.
- **`yt_BMmPLHVmnqw` (WITALT)** — **Mixed**. The 100–120 тыс. руб./м²
  headline figure describes the speaker's own full-service company's
  typical client budget tier (Turnkey-leaning), but the same source
  separately discusses "бригада" (crew) labor-only pricing tiers
  (20/30/40/60/80 тыс. руб./м²) that are closer to a Self-Managed/
  Labor-Only framing depending on which tier a reader hires directly vs.
  through a managed company. Not cleanly one category — read the
  specific figure's own context before citing it.
- **`yt_DsdLa87Acz4` (Prolife Invest)** — **Labor-Only, self-managed-
  leaning**. The 30-35-40 тыс. руб./м² "brigade" rate is explicitly
  framed by the speaker as what you pay hiring a multi-trade crew
  directly, contrasted with 50-100 тыс. руб./м² "market" pricing for the
  same scope (implicitly including more managed/institutional
  positioning). The speaker's own agency does flipping-focused renovation
  management, but this specific figure describes direct-hire crew
  pricing, not the agency's own bundled service price.
- **`yt_H61xa8n2nTk` (FLATART)** — **Itemized / Service-Specific**, not a
  whole-project figure at all — a per-linear-meter AC installation labor
  rate, historical (2017) regardless.
- **`yt__hYkf4UkCqw` / `yt_QHl1YEHMfgE` (Дома Минска, Severny Bereg
  series)** — **Not yet classifiable**, no completed cost data exists in
  either episode processed so far. Worth noting: the production appears
  to be assembling **individual specialists** (a separate designer, a
  separate replanning-approval specialist) rather than working through
  one turnkey company, which — *if* later episodes confirm this pattern
  — could make this series a genuinely useful real-world example of the
  self-managed approach. Flagged as worth watching, not asserted yet.
- **`yt_pC7CO-rpwBs` (Команда Мастеров)** — **Turnkey / Full-Service**.
  Explicitly bundles design, all labor (incl. foreman/project
  management), materials, appliances, fixtures, and custom furniture into
  one 7-stage pitch. A third Belarus turnkey data point, not a
  self-managed reference.
- **`yt_cdNwbqsLUK4` (РемонтХочу)** — **Turnkey company's own smeta,
  narrower scope: construction only.** Rough+finish labor (likely
  materials-bundled, `inferred`), but explicitly **excludes** design fee
  and furniture/appliances — a different scope than this store's other
  "full turnkey" figures. Don't compare its $/m² directly against those
  without scope-adjusting first.
- **`yt_OrKB6uSKRyk` (Бородатый Прораб)** — **Turnkey / Full-Service, the
  broadest scope in this store to date.** The 150,000 RUB/m² "full
  realization" figure explicitly bundles design, all labor, rough +
  finish materials, furniture, and specialized installation (doors, AC,
  smart home, ventilation, stretch ceilings) into one move-in-ready
  total — a wider scope than any other turnkey figure in this store.
- **`yt_6Z7uH2_rXsw` (BURO)** — **Turnkey / Full-Service, now the
  broadest scope AND highest price tier in this store, superseding
  Бородатый Прораб.** Explicit "under key" realization across three
  segments (200,000–450,000 / 450,000–1,000,000 / 1,000,000+ RUB/m²).
  Not a self-managed reference at all — useful for calibration (what a
  given quality tier actually buys), not as a target figure for this
  project's own plan.
- **`yt_8zm_5NjbGNA` (Яна Врублевская, Minsk Mir studio, 2023)** —
  **Self-Managed / Itemized, the fullest end-to-end self-managed real
  project in this store to date.** Individual specialists hired per
  trade, all materials/fixtures/appliances/furniture sourced
  independently — no managing company, no bundled design fee anywhere in
  the narration. Unlike the 44 m² смета (labor-only), this source covers
  the **complete** self-managed cost picture: rough works AND finish
  materials/fixtures/appliances/furniture for one real project. **The
  single closest structural match to this project's own planned approach
  found so far** — see full comparison in the case study §6.
- **`yt_Gp5Lr20SrtU` (Zemstandart, kids-room mistakes/tips, #181)** —
  **Labor-Only**, restating the company's own comfort-class (25,000–
  45,000 RUB/m²) vs. business-class (50,000–85,000 RUB/m²) rate bands
  already recorded from `yt_7VfZIYGUrTo` — same speaker (Sergey Saratov),
  two days apart, treated as one standing rate card, not two data points.
  The rest of the source (technique/mistakes content) carries no
  pricing.
- **`yt_OCjVd5HOcac` (Zemstandart/zemspro, video #528)** — **Turnkey /
  Full-Service.** The free "zems design" offer is explicitly bundled
  with, and only obtainable through, ordering a full project with the
  company. The 331,000 RUB/m² (107,000 labor + 224,000 materials)
  average and the ~1,000,000 RUB/74 m² bespoke design fee both describe
  this company's own bespoke-design-tier client population, self-reported
  by the designer — not a self-managed or market-wide figure. No
  self-managed/itemized data in this source.
