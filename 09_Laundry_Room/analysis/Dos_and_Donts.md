# Laundry Room - Do's and Don'ts

## Do's

| Rule | Applies To | Reason | Source |
| :--- | :--- | :--- | :--- |
| Install floor leak detection sensor near washing machine | Machine Zone | Auto shut-off on hose burst | `_Archive/processed_sources/20260727_vid1_transcript_d04723c5.txt` |
| Install floor leak detection sensors linked to automatic shut-off valves | Appliances Zone | Automatically cuts off water supply upon detecting leaks | `_Archive/processed_sources/20260727_renovation_tips_video_f23c504a.txt` |
| Select a 2-in-1 washer-dryer combo unit for Comfort-class or space-constrained apartments | Laundry Cabinet | Saves appliance hardware budget and preserves vertical space above machine for storage cabinets (reserve separate tumble dryer stacks for Business-class or high-volume bedding needs) | `_Archive/processed_sources/20260727_renovation_mistakes_budget_371bd212.txt` |
| Install dedicated dry siphon traps for washing machine drain lines | Washing Machine Zone | Prevents sewer gas odors from backing up through appliance drain lines | `_Archive/processed_sources/20260727_renovation_guide_mistakes_3_a0e895b1.txt` |
| Prefer a heat-pump tumble dryer over any other drying technology, regardless of standalone/combo casing | Tumble Dryer | Gentlest drying technology on fabric — clothes come out soft, warm, dry, often skipping ironing entirely; only downside is a longer cycle time | `11_Budget_and_Planning/_supporting/knowledge/sources/YT_sd2XYBZY-K8_kruglov_bathroom_2026_top10` |
| When budget/space allow, prefer separate washer and dryer units over a combo unit | Laundry Cabinet | The source's own stated "ideal" setup — two independent machines, each fully dedicated to its task, vs. the compromises of a combo unit; contrast with this page's own combo recommendation above for Comfort-class/space-constrained cases — a segment-tier tradeoff, not a contradiction | `11_Budget_and_Planning/_supporting/knowledge/sources/YT_sd2XYBZY-K8_kruglov_bathroom_2026_top10` |
